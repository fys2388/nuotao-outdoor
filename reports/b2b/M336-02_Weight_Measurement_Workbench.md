## 1. 采集规范（每款必填）
| 字段 | 要求 |
|---|---|
| 商品净重 | 裸品称重，电子秤≥0.01kg |
| 包装后毛重 | 重新包装后称重，> 净重 |
| 包装长宽高 | 统一 cm，三边各测 3 次取均值 |
| 体积重 | 长×宽×高 ÷ 实际除数 |
| 体积重除数 | 依据实际承运商/货代规则，禁止默认 5000 |
| 计费重量 | 取 max(实重, 体积重) 按承运商进位规则 |
| 原始证据 | 净重照/毛重照/尺寸照，双人签字 |
**禁止**：将品类平均重量标记为实测重量；未实测保持 ESTIMATED/MISSING。
