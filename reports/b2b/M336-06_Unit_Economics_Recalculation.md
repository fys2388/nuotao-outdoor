## 1. 口径定义（防重复/遗漏）
```
到岸(中性) = 采购 + 头程 + 尾程 + 关税 + 燃油   [清关费/代垫费 MISSING 不默认为0 → 到岸低估]A 商品毛利率 = (售价 − 到岸 − 支付 − 退货) / 售价
B 履约贡献率 = (售价 − 到岸 − 支付) / 售价      [不含CAC、不含退货]
C 扣CAC净利率 = (售价 − 到岸 − 支付 − 退货 − CAC) / 售价
悲观：采购+20%、关税+20%、运费+15%；乐观：采购−20%、关税−20%、运费−15%
```
