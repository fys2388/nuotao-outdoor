# Nuotao Product Score™ — 选品框架 V3.0

> 版本：V3.0
> 日期：2026-09-08
> 前置文档：`docs/product_selection_logic_v2.0.md`（11 维运营评分）、`docs/product_strategy.md`（品牌定位与 Hero 策略）
> 升级背景：第三方评审指出「后台 AI 能力领先于前台品牌表达」，V3.0 的核心目标是**把后台评分能力品牌化**，让选品逻辑从「找到更多商品」转向「主动拒绝不适合 Nuotao 的商品」。

---

## 一、V3.0 核心变化

| 维度 | V2.0（运营评分） | V3.0（品牌化双轨） |
|---|---|---|
| 评分目的 | 内部运营决策 | 内部决策 + 前台品牌资产 |
| 评分维度 | 11 维（运营视角） | **双轨**：11 维运营分 + 6 维 Nuotao Score |
| 品牌契合 | 隐含在「差异化空间」中 | **独立 Brand Fit 维度**，一票否决级 |
| 拒绝逻辑 | 分数低自然淘汰 | **主动拒绝清单**：明确哪些产品即使分数高也不做 |
| 消费者可见 | 无 | Nuotao Score 可展示在商品详情页 |
| 选品漏斗 | 无明确漏斗 | 100→60→20→8→3→1-2 明确漏斗 |

> V2.0 的 11 维运营评分**不废弃**，作为内部运营的精细评估工具保留；V3.0 新增的 Nuotao Score 是面向品牌和消费者的简化评分，两者并行。

## 二、Nuotao Product Score™（品牌评分，6 维）

这是未来可以展示在商品详情页、成为品牌护城河的评分体系。每个维度 0-10 分，加权后得到 0-100 的 Nuotao Score。

### 2.1 评分维度与权重

| 维度 | 权重 | 0-10 分定义 | 数据来源 |
|---|---|---|---|
| **Value（性价比）** | 25% | 同等品质下价格优势；全成本利润率健康度 | 1688 采购价 + 物流 + 竞品价格带 |
| **Utility（实用性）** | 20% | 解决真实户外场景问题的能力；使用频率；多功能性 | 产品功能分析 + 场景匹配 + 评论痛点 |
| **Weight & Packability（轻量便携）** | 15% | 重量、体积、收纳便利性；Nuotao 品牌核心主张 | 产品参数 + 物流重量实测 |
| **Durability（耐用性）** | 15% | 材质、工艺、供应商品质达标率、预估退货率 | 供应商资质 + 材质分析 + 1688 品质数据 |
| **Brand Fit（品牌契合）** | 15% | 是否符合「专业户外装备品牌」定位；是否削弱品牌聚焦 | 品牌定位匹配度 + 品类战略 + 价格带定位 |
| **Differentiation（差异化）** | 10% | 相比竞品有可讲述的改进点；AI 生图提升空间；内容潜力 | 竞品对比 + 产品分析 + 内容评估 |
| **合计** | **100%** | | |

### 2.2 评分计算

```
Nuotao Score = Σ(维度分 × 权重) × 10
```

示例（一款轻量化露营灯）：

| 维度 | 得分（0-10） | 加权 |
|---|---|---|
| Value | 9.2 | 2.30 |
| Utility | 9.0 | 1.80 |
| Weight & Packability | 9.5 | 1.43 |
| Durability | 8.0 | 1.20 |
| Brand Fit | 9.5 | 1.43 |
| Differentiation | 8.5 | 0.85 |
| **合计** | | **9.01 → Nuotao Score 90/100** |

### 2.3 评分等级与决策

| Nuotao Score | 等级 | 决策 | 前台展示 |
|---|---|---|---|
| ≥ 85 | **Hero Candidate** | 优先测试，目标成为 Hero Product | 展示评分 + "Why we recommend it" |
| 75-84 | **Core** | 可上架，核心品类主力 | 展示评分 |
| 65-74 | **Long-tail** | 可上架，长尾填充，不占营销资源 | 不展示评分（或展示较低调） |
| < 65 | **Reject** | 拒绝 | 不上架 |

> 注意：Nuotao Score ≥ 65 只是「可上架」的必要条件，不是充分条件。还必须通过下方第三节的「一票否决」检查。

## 三、一票否决规则（主动拒绝清单）

V3.0 的核心转变：**不是分数高就一定做，而是先过「拒绝清单」，再看分数。** 以下任何一条触发，无论评分多高，直接拒绝。

### 3.1 合规与安全否决（硬门槛）

| # | 规则 | 说明 |
|---|---|---|
| V1 | 知识产权侵权 | 外观专利、商标、品牌图案侵权风险（如防水手机袋 US1009474S 案例） |
| V2 | 法规合规 | 美国 CPSC/CPSIA、欧盟 REACH、电池运输、食品接触 FDA 等无法满足 |
| V3 | 安全风险 | 产品存在人身安全隐患且无法通过设计规避 |
| V4 | 违禁品 | 目标市场禁止进口或销售的品类 |

### 3.2 品牌契合否决（V3.0 新增）

| # | 规则 | 说明 |
|---|---|---|
| V5 | **品牌聚焦破坏** | 产品品类与 Nuotao「专业户外装备」定位严重不符（如纯泳装、城市时尚品、玩具） |
| V6 | **低价杂货感** | 产品天然属于「$5 以下 impulse buy」品类，会拉低品牌认知（如廉价钥匙扣、一次性用品） |
| V7 | **与现有 Hero 冲突** | 与已确定的 Hero Product 直接同质化竞争，无差异化 |
| V8 | **Brand Fit < 5/10** | Nuotao Score 中 Brand Fit 维度低于 5 分，直接否决 |

### 3.3 商业可行性否决

| # | 规则 | 说明 |
|---|---|---|
| V9 | 物流不可行 | 运费占售价 > 40%，或属于国际运输禁运品（如纯气罐） |
| V10 | 利润不可行 | 全成本利润率 < 20%，且无法通过定价/组合优化 |
| V11 | 供应商不可行 | 无合格供应商（C 级以下），或无法提供样品/认证 |
| V12 | 退货风险过高 | 预估退货率 > 15%（如服装尺码、电子产品故障率） |

## 四、选品漏斗（V3.0 明确化）

```
100 个 1688 候选
    ↓ 【确定性规则过滤】V1-V4 合规否决 + V9-V12 商业否决
60 个 通过初筛
    ↓ 【11 维运营评分】V2.0 体系快速评分，≥70 分进入
20 个 深度候选
    ↓ 【Nuotao Score + Brand Fit 否决】V3.0 品牌评分 + V5-V8 品牌否决
8 个 测试候选
    ↓ 【小批量测试】30-100 件，4-8 周数据验证
3 个 验证通过
    ↓ 【Hero 评审】人工审批 + Hero 标准检查
1-2 个 Hero Product
```

### 漏斗各阶段产出

| 阶段 | 产出 | 负责人 |
|---|---|---|
| 100→60 | 初筛清单（含拒绝理由） | 确定性规则 + AI 辅助 |
| 60→20 | 11 维运营评分表 | AI Product Analyst |
| 20→8 | Nuotao Score 报告 + Brand Fit 评估 | AI Product Analyst + 人工复核 |
| 8→3 | 测试数据报告（转化/ROAS/退货） | AI 商业分析 |
| 3→1-2 | Hero 评审决议 | 人工审批 |

## 五、双轨评分映射关系

V2.0 的 11 维运营评分与 V3.0 的 6 维 Nuotao Score 不是替代关系，而是**粗细搭配**：

| Nuotao Score 维度 | 对应 V2.0 11 维维度 | 映射方式 |
|---|---|---|
| Value（25%） | 全成本利润率（15%）+ 销量验证（10%） | 利润率为主，销量验证辅助 |
| Utility（20%） | 市场热度（15%）+ 差异化空间（5%） | 市场需求 + 产品功能匹配 |
| Weight & Packability（15%） | 物流支持（5%）+ 部分差异化空间 | 重量/体积直接驱动物流成本 |
| Durability（15%） | 产品质量（10%）+ 供应商资质（5%） | 品质达标率 + 供应商能力 |
| Brand Fit（15%） | **V3.0 新增**（V2.0 中隐含在差异化中） | 品牌定位匹配 + 品类战略 + 价格带 |
| Differentiation（10%） | 亚马逊竞争度（10%）+ AI 生图难度（5%）+ 季节性（5%） | 竞争蓝海 + 内容潜力 + 时机 |

> 实现层面：11 维运营评分的明细数据可以自动映射计算 Nuotao Score，不需要人工重复打分。Brand Fit 维度需要额外的品牌规则配置。

## 六、Nuotao Score 前台展示规范

当 Nuotao Score ≥ 75 时，可以在商品详情页展示。展示格式：

```
┌─────────────────────────────────┐
│  Nuotao Score  92 / 100         │
│  ★★★★★  Hero Candidate          │
├─────────────────────────────────┤
│  VALUE              9.2          │
│  UTILITY            9.4          │
│  WEIGHT & PACKABLE  8.8          │
│  DURABILITY         8.5          │
│  BRAND FIT          9.6          │
│  DIFFERENTIATION    9.1          │
├─────────────────────────────────┤
│  Why we recommend it             │
│  ✓ High utility                  │
│  ✓ Low shipping burden           │
│  ✓ Strong price-to-performance   │
│  ✓ Low return risk               │
│  ✓ Strong test potential         │
└─────────────────────────────────┘
```

展示规则：
- **≥ 85（Hero Candidate）**：完整展示 6 维评分 + "Why we recommend it"
- **75-84（Core）**：展示总分 + 3 个最强维度
- **< 75**：不展示评分
- 所有展示的评分必须有对应的内部评分记录可追溯（`product_analysis_runs` 表）

## 七、与现有系统的对接

### 7.1 数据模型变更

需要在 `products` 或 `product_intelligence` 表中增加：

| 字段 | 类型 | 说明 |
|---|---|---|
| `nuotao_score` | DECIMAL(5,2) | Nuotao Score 总分（0-100） |
| `nuotao_score_dimensions` | JSONB | 6 维分项得分 |
| `brand_fit_score` | DECIMAL(3,1) | Brand Fit 维度分（0-10），<5 触发否决 |
| `reject_reasons` | JSONB | 触发的一票否决规则列表 |
| `funnel_stage` | VARCHAR | 当前所处漏斗阶段 |

### 7.2 Product Analyst Agent 升级

现有 `ProductAnalysisOutput` schema 需要扩展：

```python
# 新增字段（在现有 decision/confidence/pricing/test_plan 基础上）
nuotao_score: Decimal  # 0-100
nuotao_dimensions: dict[str, Decimal]  # 6 维分项
brand_fit_score: Decimal  # 0-10
reject_flags: list[str]  # 触发的否决规则 ID
funnel_stage: str  # candidate / screened / deep / test / hero
```

### 7.3 提示词升级

`PRODUCT_ANALYST` 提示词需要增加：
- Brand Fit 评估指令（对照品牌定位红线）
- 主动拒绝检查清单（V1-V12）
- Nuotao Score 6 维评分指令
- 「Why we recommend it」生成指令（最多 5 条，必须基于数据）
