## 1. 技术 / 产品细节

### 1.1 官方确认的核心卖点（来源：COODY 官方新闻稿 via 时事 / MANTANWEB）

- **空气框架（エアフレーム）免立杆**：注入空气即成型，省去复杂杆件组装（[Jiji 官方新闻稿](https://www.jiji.com/jc/article?k=000000067.000102102&g=prt)）。
- **约5分钟设营（手泵）**：付属手动气泵约5分钟完成设营；**电泵则"接上、按按钮、自动充气、达到合适量自动停止"**（原文：*電動エアポンプなら繋いでボタンを押すだけ。あとは自動でエアが入り、適量に達すると自動で停止します*）。
- **尺寸**：约 **3.6m（宽）× 2.8m（深）× 2.3m（高）**，约 **10㎡**，可容 1–4 人（[MANTANWEB](https://mantan-web.jp/prtimes/article/20260724prt00m200001073a.html)）。
- **材质**：外幕为**聚棉（聚酯65% + 棉35%）**；地板为聚酯；门/窗为网布·聚棉·PVC。棉质带来优良透气与保温，夏凉冬暖、减少结露（[@DIME 前代10.0报道](https://dime.jp/genre/1953750/)，PRO 沿用同材质体系）。
- **重量**：帐篷本体约 **32kg**，附件约 **10.6kg**，合计约 **42.6kg**（较重，属高端大型气柱帐篷典型水平）。
- **开口设计**：**大型侧窗 + 前后4分割门**（可局部开合、双拉链可拆卸）；侧窗可撑杆上掀**当遮阳天幕用**（[Jiji](https://www.jiji.com/jc/article?k=000000067.000102102&g=prt)）。
- **扩展性**：可与 coody PRO 系列 / 空气天幕 PRO **连接**（官方口径"可连接"；需对应产品与另售连接件）。
- **颜色**：米色 / 橄榄绿 / 黑色 / 灰色。

### 1.2 商品构成（来源：[MANTANWEB](https://mantan-web.jp/prtimes/article/20260724prt00m200001073a.html)）

气垫帐篷、前网门×2（本体已装）、可拆卸地板×1（本体已装）、防雨布（fly sheet）×1、侧透明窗×2、透气部件×4、张索（本体已装）、地钉、**手泵**。（注：电泵为选配/另售）

### 1.3 前代 10.0 的技术细节（对照，来源：[@DIME 2025-04-12](https://dime.jp/genre/1953750/)）

前代 10.0（非PRO）：3.6×2.8×**2.2m**（中心高）、手泵设营 **10–15分钟**、一般价 238,000日元 / Makuake 190,400日元；聚棉厚布保温透气、前门/后门拉链式可拆卸全开、门有"TPU+聚棉"与"网+聚棉"两种、窗有"网+聚棉"与"TPU"两种；**顶部 TPU 透明窗（可望天）+ 烟囱孔（可装柴炉）+ 空调/电源引入孔**。→ PRO 在开口、窗、天顶、可连接性上进一步升级。

### 1.4 材料/结构技术背景（来源：天津海关报道，2025-09）

代工厂军鑫科技产品采用**航空级 PVC 气柱 + 智能温控膜材**，可在 **-25℃～50℃** 稳定使用；"传统帐篷搭建需30分钟，而我们的产品只需一台泵，**3分钟即可成型**"（[中国纺织报/天津海关](https://www.ctn1986.com/index.php?c=content&a=show&id=121336)、[北方网](https://news.enorth.com.cn/system/2025/09/09/058714201.shtml)）。→ 印证气柱结构与极寒/极热适应性是核心工艺壁垒。

### 1.5 电动泵规格

官方站存在 **coody 電動エアポンプ2** 页面（[coody-jp.com/airpump/](https://coody-jp.com/airpump/)），台湾渠道有 **Coody 智能無線電動幫浦 CQ-100** 型号（[campworld 检索结果](https://www.campworld.tw/en/products/b35280)），但**页面为 JS 渲染，未能抓取详细参数（PSI/电池/静音等）→ 未查到**。官方新闻稿仅确认"电泵自动充气、达量自动停止"功能。

### 4.2 风险判断

- **气柱帐篷基本原理（充气梁承重）属公知/公共领域**，几十年历史，单纯"气柱+帐篷"不构成强保护。
- 真正的风险点在于**具体结构/机构设计**：军鑫科技 15项专利很可能覆盖**特定气柱布局、阀体、快速成型、连接结构、温控膜材**等。但**未查到具体专利号与权利要求**，无法判断是否阻断同类。
- 海关备案的 18项知识产权意味着军鑫/品牌方**具备在海关主动扣货维权的工具**，若 Nuotao 走同一/类似供应链，需特别注意**不要复制其商标、外观与受保护结构**。
- **结论：FTO 风险为「中」，且信息不完整。** 强烈建议开发前委托**专业专利检索机构做 FTO 自由实施分析**（中国+韩国+日本+美国），重点查：气柱帐篷结构、自动充气/自动停止机构、连接结构、温控膜材、外观设计专利。**本次未能核验具体阻断专利 → 该项如实标注。**

## 5. Nuotao Outdoor 适配建议

### 5.1 是否值得做？

- **市场信号正面**：Makuake 单项目 3,367万日元/173人，人均≈19.5万日元，且**3小时破1,000万日元**（[MANTANWEB](https://mantan-web.jp/prtimes/article/20260724prt00m200001073a.html)），说明高端气柱帐篷在日韩有真实付费意愿；品牌已全球多市场分销。
- **但有明显风险**：
  1. **同质化**：核心卖点（气柱+聚棉+免杆+电泵）已被 coody 占位，且其**供应链同源可寻**，复制门槛不高。
  2. **重量/物流痛点**：整机约42.6kg，属大件重货，跨境物流成本高、海外仓压货重。
  3. **价格带竞争**：日零售26.4万日元，属高端；Nuotao 若无品牌/内容差异化，难以支撑同等溢价。
  4. **专利/知识产权不确定性**：军鑫15项专利+18项海关备案，FTO 未做。

### 5.2 差异化切入点（建议）

1. **轻量化**：用**TPU气柱 + 更低克重聚棉/棉混**，把整机从~42kg 降到 ~25–30kg，主打"单人可搬"——这是 coody 尚未解决的痛点（其整机含附件42.6kg）。
2. **结构创新**：**模块化/分体式气柱**（快速更换单根气柱、分离式充气）、**防塌/补气智能电泵**（带压力传感器自动补气、低压报警），绕开"电泵自动停止"的既有实现。
3. **细分场景**：**车尾帐篷/快开式**、**四季（含烟囱孔+空调孔+冬季温控膜）**、**防灾/应急救援版**（军鑫已在做"应急救援领域中国名片"→ 有 ToB 需求）。
4. **连接生态**：做**通用连接标准**（跨品牌适配器），不绑定单一品牌。
5. **材料差异化**：环保可回收面料（coody 宣传"环保可持续材料"，可做更高回收比例）+ 阻燃/抗菌涂层，突出安全。

### 5.3 落地难度评分（1=极易，5=极难）
