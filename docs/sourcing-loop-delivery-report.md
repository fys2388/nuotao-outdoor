## 四、真实1688选品录入模板

### 手动录入步骤

1. **在1688网站搜索产品**
   - 访问：https://www.1688.com
   - 搜索关键词（如"户外保温水壶"、"露营灯"、"折叠椅"）
   - 筛选条件：实力商家、深度验厂、回头率>30%、月销>1000

2. **记录产品信息**
   ```
   产品名称：（1688真实标题）
   1688链接：（详情页URL）
   供应商名称：（真实工厂/贸易商）
   供应商代码：（自定义，如SUP-001）
   采购价：（1688真实价格，注意起批量）
   起订量(MOQ)：（最小起订量）
   交货天数：（供应商承诺交货时间）
   产品规格：（尺寸、重量、材质、颜色）
   趋势评分：（1-10分，基于月销量、增长率、竞争度）
   ```

3. **录入到系统**
   - 方式一：系统后台"选品管理"→"新建选品"
   - 方式二：调用API `POST /api/v1/products/intake`
   - 方式三：CSV批量导入 `POST /api/v1/products/intake/csv`

### CSV导入模板

```csv
sku,name,description,category,brand,source,source_url,tags,attributes,purchase_cost_cny,total_landed_cost_cny,supplier_code,moq,lead_time_days,trend_score,target_market
```
