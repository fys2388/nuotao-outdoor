## 规避卡 1｜多功能工具卡 — 去刀片款

| 项 | 内容 |
|---|---|
| 问题依据 | 军刀卡含刀刃 = 美国 18+ 年龄限制、部分平台禁售、海关查验风险（合规分 60，9 款最低） |
| **规避动作** | ① 只选**无任何刀刃**的卡片款：功能限开瓶器/扳手/螺丝批/剥线/度量尺，**严禁带刀片、刀刃口、锯齿刃**；② 报关品名写 "Bottle Opener Card" 或 "Multi-tool Card (Blade-free)"，**禁止出现 knife / blade / cutter** 字样；③ 主图与 A+ 文案同步去刀具暗示（不拍切割场景） |
| 1688 选品关键词 | 「多功能工具卡 无刀」「开瓶器卡 不锈钢 户外」「EDC 工具卡 去刀片」 |
| 候选供应商（已实查） | 阳江锐鑫 11 年 / 东阳誉铭（成交 3.5 万件、回头率 38.1%）/ 佛山格宜美（¥3.1 月销 1165 件，48h 发货） |
| 验收标准 | ✅ 实物无刀刃（目检+刀口测试）｜✅ 供应商确认可提供非刀具报关资料｜✅ 文案/主图无 knife 类词 |
| 上架前检查点 | 平台类目选择 "Bottle Openers" 而非刀具类目；采购订单备注 "No blade" 写进合同条款 |

## 规避卡 2｜迷你急救包 — 去药物（器械 only）

| 项 | 内容 |
|---|---|
| 问题依据 | 含药膏/药片/含药酒精棉 = 美国 FDA 按药品监管，无 NDC/OTC 注册即违规（合规分 62） |
| **规避动作** | ① 内容物**只含非处方器械类**：绷带、纱布垫、创口贴（无药）、三角巾、医用胶带、棉签（无药）、镊子、小剪刀、急救毯、CPR 面罩；② **严禁**：药膏/软膏、口服药片、含酒精或苯扎氯铵的消毒棉片；③ 英文命名 "First Aid Kit (Non-Medical)"，listing 与五点描述**禁止出现 medicine / drug / antiseptic / pain relief** 等词 |
| 1688 选品关键词 | 「急救包 跨境 无药」「急救包 器械套装 出口」＋ 向供应商索要内容物清单，逐个核验成分 |
| 候选供应商（已实查） | 东莞瑞信 10 年（¥10.5 mini EVA 款）/ 义乌中驰 11 年（¥4.51 九件套）——需供应商书面确认内容物清单 |
| 验收标准 | ✅ 内容物清单逐项核验无药物类｜✅ 供应商可提供非药品报关资料｜✅ 文案无 medical 功效宣称（仅"first aid supplies"） |
| 上架前检查点 | 若供应商坚持含酒精棉片 → 要求替换为"生理盐水湿巾"或直接去掉；必要时按"一般医疗器械"评估是否需 FDA 机构注册（建议咨询货代/律师） |

## 规避卡 3｜防水手机袋 TPU — 外观专利规避（最高优先）

| 项 | 内容 |
|---|---|
| 问题依据 | 美国外观设计专利 **US D1009474 S**（2024-01-02 下证，公开信息来自跨境侵权预警 508 期）：同款月销 3000+、留评 3000+，**上架即面临下架/冻结风险**（合规分 88→68） |
| **规避动作** | ① **第一步（本清单首个动作）**：在 Google Patents 检索 `USD1009474` 下载专利附图，与候选 1688 款实物图逐项比对；② 与苍南胜辉（12 年）等供应商共创改款，**至少变更 2 处以上整体视觉特征**：气囊形态/数量（如双气囊→单气囊+边条）、卡扣与密封条结构外观、挂绳方式（颈挂→斜挎/腕带）、轮廓长宽比、表面纹理（光面→磨砂/波纹）；③ 改款打样/要 3D 图后与专利附图二次比对（整体视觉效果不得实质相同）；④ 出具《规避比对说明》留档 |
| 1688 选品关键词 | 「手机防水袋 磨砂 TPU」「手机防水袋 斜挎 大容量」「手机防水袋 定制 改款」 |
| 候选供应商（已实查） | 苍南胜辉 12 年（¥4.4-6.5，月销 1121 PCS）——优先要改款打样；东莞海思凯 5 年（高透款备选） |
| 验收标准 | ✅ 已下载专利附图并比对留档｜✅ 改款与专利附图整体视觉效果实质不同（≥2 处结构变更）｜✅ 出具《规避比对说明》 |
| 上架前检查点 | 改款打样后建议委托代理律师做一次 FTO（自由实施）意见（¥1-2k 级）再定稿；**专利规避未完成前该 SKU 不进第 1 批上架队列** |
