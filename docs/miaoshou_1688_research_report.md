# 妙手跨境 1688功能调研报告

## 📋 研究目标

分析妙手跨境在1688平台上使用的API功能和业务流程，为Nuotao Outdoor ERP系统对接提供参考方案。

---

## 一、妙手跨境 1688核心功能

### 1. 商品搜索与选品

| 功能 | 说明 | 对应API |
|------|------|---------|
| **关键词搜索** | 输入关键词搜索1688商品 | `product.search.keywordQuery` |
| **图片搜款** | 上传商品图片搜索同款/相似款 | `product.search.imageQuery` |
| **链接直达** | 输入1688商品链接直接获取详情 | `product.search.queryProductDetail` |
| **跨境专供筛选** | 筛选支持跨境发货的供应商 | API内置筛选参数 |

### 2. 商品信息采集

| 功能 | 说明 |
|------|------|
| **一键采集** | 批量采集商品标题、图片、价格、SKU |
| **主图获取** | 自动获取商品主图（最多9张） |
| **详情页爬取** | 获取商品详情页内容 |
| **SKU映射** | 自动识别颜色/尺寸等规格变体 |
| **价格获取** | 获取阶梯价格、跨境分销价 |

### 3. 商品上架

| 功能 | 说明 |
|------|------|
| **多平台铺货** | 一键上架到Shopee、Lazada、TikTok、Amazon等 |
| **智能类目匹配** | 自动匹配目标平台类目 |
| **标题优化** | AI生成符合平台规范的标题 |
| **价格计算** | 自动计算零售价（含利润加成） |
| **库存同步** | 实时同步1688库存到店铺 |

### 4. 订单处理

| 功能 | 说明 |
|------|------|
| **一键下单** | 下游出单后自动创建1688采购订单 |
| **批量采购** | 多订单合并批量下单 |
| **订单同步** | 实时同步1688订单状态 |
| **物流追踪** | 同步物流信息，自动更新订单状态 |

### 5. 智能采购建议

| 功能 | 说明 |
|------|------|
| **缺货提醒** | 根据库存数据生成补货建议 |
| **采购计划** | 智能推荐采购数量和时机 |
| **供应商评估** | 提供货源评分、揽收率等指标 |

## 二、1688跨境寻源通API详解

### 核心API列表

#### 1. 商品搜索类

| API | 接口名 | 功能 |
|-----|--------|------|
| `com.alibaba.fenxiao.crossborder:product.search.keywordQuery` | 关键词搜索 | 搜索跨境专供商品 |
| `com.alibaba.fenxiao.crossborder:product.search.imageQuery` | 图片搜索 | 以图搜款 |
| `com.alibaba.fenxiao.crossborder:product.search.queryProductDetail` | 商品详情 | 获取完整商品信息 |

**keywordQuery参数示例：**
```json
{
  "keyword": "月亮椅 户外",
  "categoryIds": "1037622",
  "priceMin": "30",
  "priceMax": "50",
  "page": 1,
  "pageSize": 20,
  "sortType": "sales DESC"
}
```

**返回字段示例：**
```json
{
  "products": [
    {
      "productId": "844058953087",
      "title": "跨境加棉月亮椅户外露营折叠椅",
      "mainImage": "https://cbu01.alicdn.com/img/...",
      "price": "35.8",
      "minOrder": 1,
      "salesVolume": 12580,
      "supplier": {
        "memberId": "huanchang",
        "companyName": "固安栖野户外用品有限公司",
        "location": "河北省廊坊市"
      },
      "crossBorder": true,
      "fulfillmentScore": 4.5
    }
  ]
}
```

## 五、关键差异点

### 妙手 vs Nuotao 的差异

| 维度 | 妙手跨境 | Nuotao Outdoor |
|------|---------|----------------|
| **定位** | SaaS服务商，服务多个卖家 | 自营ERP，服务自身业务 |
| **平台支持** | 多平台（Shopee/Lazada/TikTok等） | 单一平台（WooCommerce独立站） |
| **采购模式** | 代发一件起订 | 批量采购+自囤库存 |
| **定价策略** | 自动计算零售价 | 自定义定价公式 |
| **供应链** | 对接多个供应商 | 固定供应商合作 |
