## 1. 前置结论：web_fetch 探测失败

**结论**：三家主流货代的实时报价页面已完全登录墙化，无法通过公开 URL 抓取。

| 货代 | URL 探测结果 |
|---|---|
| 云途 Yun Express | `yunexpress.com/en/price-list` → 404（改版 Nuxt）；`yunexpress.com/en` → 404 |
| 燕文 YW56 | `yw56.com.cn` → 200 但只返回导航菜单 + 客服热线 400-108-5656；实时报价必须登录 `portal.yw56.com.cn` |
| 递四方 4PX | `4px.com/us` → 404 nginx |
| 燕文追踪 | `track.yw56.com.cn` → 200 但只是运单追踪页，不含报价 |

**含义**：
- 中国货代已普遍转向「登录客户中心获取实时报价」模式，无法通过爬虫/浏览器直接拿数
- 必须走「人工注册 + 询价单」路径
- 或购买物流比价工具（Sellersprite / Tailored Logistics / 集运易）

**执行策略**：走「人工询价单」路径，见下文 §2-§6。

## 2. 询价对象候选（3-5 家）

**推荐询价对象（4 家 + 1 备选）**：

| 排序 | 货代 | 网址 | 主打产品 | 预估时效 | 目标角色 |
|---|---|---|---|---|---|
| 1 | 云途 Yun Express | yunexpress.com | EUB / S5101 / XDE | 8-15 天 | **主力候选** |
| 2 | 燕文 YW56 | yw56.com.cn | 燕邮小包 / S5101 | 8-14 天 | **主力候选** |
| 3 | 递四方 4PX | 4px.com | GDS-003 | 10-20 天 | **主力候选** |
| 4 | 顺友 SFC | shunyoush.com | S5101 | 8-15 天 | 备选 |
| 5 | 邮政小包 EUB | 通过 4PX/云途走 | EUB | 15-30 天 | 慢件兜底 |

**询价原则**：
1. 至少 3 家主力询价（选报价最低 + 时效最优）
2. 1 家备选（当主力爆仓时切换）
3. 保留 EUB 邮政小包作兜底（时效差但便宜）

## 3. 询价单模板（发给每家货代）

**通过邮件 + 微信/电话双通道发送**：

```
收件方：货代销售（各货代官网「联系销售」入口）
主题：[Nuotao Outdoor] 跨境电商美国直发合作询价 - 60 SKU 户外小件

正文：

您好，

我们是 Nuotao Outdoor（品牌名），中国跨境电商独立站卖家，产品为户外小件
（帐篷配件/露营灯/炊具/收纳/水具/家具/配件 7 大系列，60 SKU，多数 500g-2kg）。

现寻求长期合作，请提供以下报价单：

【产品数据（重量区间）】
- 帐篷配件：200-500g 为主
- 户外露营灯：100-300g 为主
- 炊具餐具：300-800g 为主
- 收纳防潮：100-300g 为主
- 水具：300-800g 为主
- 户外家具：500-2000g 为主
- 配件：50-200g 为主

【订单量预测】
- 阶段 1（M0-M9）：100-1000 单/月，单件 0.3-2kg
- 阶段 2（M9-M15）：500-1500 单/月，单件 0.3-2kg
- 旺季 Q4：峰值 3-5x 月均

【目的国】
- 主要：美国全境（西海岸 40% + 中西部 30% + 东海岸 20% + 东南部 10%）
- 次要：欧盟 27 国 + 英国（阶段 2b 才做）

【询价内容】
1. 各产品的美国直发 DDP 报价（含关税、末派）
2. 时效承诺（平均 + P90）
3. 起量折扣（月 100 / 300 / 500 / 1000 单）
4. 计费规则：实重 vs 体积重、抛比系数
5. 旺季附加费（Q4 是否有旺季涨价）
6. 退货流程：拒收后能否退中、退货率

10. 系统对接：WooCommerce 订单自动导出的 API 或 CSV

【HS Code 参考（供报关用，取自 cross_border_compliance_knowledge_base.md §2.1）】

- 9404.90 睡袋
- 9401.69/79 折叠椅
- 7321.11/81 炉具
- 8513.10 手电筒/露营灯
- 3924.10 水壶/水袋（塑料）
- 4202.92 背包/收纳袋
- 9405.20 户外灯具（LED）
- 6307.90 帐篷配件/收纳篷布
- 7326.90 户外钢制配件
- 8543.70 电池/电子配件

【合规声明】
所有产品将提供 GCC（General Certificate of Conformity）通证，符合 CPSC 通用要求。

请尽快回复报价单，我们希望 M1 前完成主力货代签署。

Nuotao Outdoor
```

## 5. 决策树：何时切换主力货代

```
问题：主力货代（假设是云途）出问题？

├─ 月单量 < 100 且成本敏感 → 保持主力，不用切换
├─ 旺季爆仓（时效 > 25 天）→ 立即切换 30% 单量到备胎
├─ 拒收率 > 5% → 立即切换 50% 单量到备胎
├─ 单价比备选贵 30% → 季度末评估是否重谈
├─ 政策变更（DDP 涨价）→ 30 天内重签合同或切换
└─ 供应链断供（工厂停发）→ 切换 100% 到备胎
```

## 6. 阶段 1 履约目标值（DTC 运营手册 §5.2）

用作询价单回复后的验收基准：

| 指标 | 阶段 1 目标 | 熔断阈值 |
|---|---|---|
| 平均时效 | 8-22 天 | > 25 天连续 2 周 |
| 单价（$0.5kg 首重） | $5-8/单 | > $10/单 |
| 抛比系数 | 1:6000 或 1:5000 | 1:4000（成本失控） |
| 拒收回邮率 | < 3% | > 5% 触发切换 |
| 首件免运费门槛 | $49-59 | <$39（利润受损）|

| 缺口 | 原因 | 人工替代方案 |
|---|---|---|
