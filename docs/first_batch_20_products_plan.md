---

## 一、选品策略总览

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **轻小件优先** | 优先选择<1kg产品，国际物流成本低，全成本利润率高 |
| **高利润率** | 全成本利润率目标>50%（采购价+物流+平台+营销） |
| **户外刚需** | 选择露营/徒步/钓鱼等户外场景的刚需产品 |
| **差异化空间** | 1688原图有中文/非白底，可通过AI生图大幅提升转化率 |
| **供应商优质** | 优先超级工厂，回头率>40%，品质达标率>95% |

### 1.2 产品重量与利润率关系

| 重量区间 | 国际物流费(估) | 全成本利润率 | 推荐度 |
|----------|----------------|-------------|--------|
| <0.5kg | ¥40-60 | 60-75% | ⭐⭐⭐⭐⭐ |
| 0.5-1kg | ¥60-100 | 50-65% | ⭐⭐⭐⭐ |
| 1-2kg | ¥100-180 | 35-50% | ⭐⭐⭐ |
| 2-3kg | ¥180-280 | 25-40% | ⭐⭐ |
| >3kg | >¥280 | <30% | ⭐ |

> ⚠️ 关键发现：重件产品（>2kg）的全成本利润率仅20-30%，远低于预期。第一批优先选择<1kg的轻小件产品。

### 3.2 每个产品的标准上架流程

```
Step 1: 1688选品（搜索→筛选→V2.0评分→确认）
Step 2: 下载3-5张不同角度产品图作为I2I参考
Step 3: 生成AI文案（标题+描述+卖点+SEO关键词）
Step 4: 图片合规检查（中文/非白底/侵权元素）
Step 5: AI生图（5张主图+6张详情页，严格按照Prompt模板库）
Step 6: 生图质量检查（外观一致性/文字/背景/多样性）
Step 7: WooCommerce上架（产品创建+图片上传+属性+库存+采购关联）
Step 8: 前台验证（产品页面显示正常+图片完整+价格正确）
```

## 四、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 重件产品利润率低 | 利润不达预期 | 提价10-20%，或优化物流渠道，或组合销售提升客单价 |
| AI生图产品外观变形 | 产品图与实物不符 | 严格I2I图生图，生成后人工检查，不合格重新生成 |
| 1688供应商断货 | 无法履约 | 选择2-3个备选供应商，库存设置合理阈值 |
| 季节性产品滞销 | 库存积压 | 提前1-2个月上架旺季产品，淡季产品控制库存 |
| 专利侵权风险 | 法律纠纷 | 选品时核查外观专利，避免明显侵权设计 |
