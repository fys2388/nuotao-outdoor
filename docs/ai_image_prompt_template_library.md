# Nuotao Outdoor AI生图Prompt模板库 V1.0

> 版本：V1.0
> 创建日期：2026-09-06
> 适用模型：Seedream 5.0 Pro（I2I图生图）
> 核心原则：产品外观100%还原 + 视觉多样化 + 电商转化率优化

---

## 一、生图总原则

### 1.1 不可动摇的铁律

| 铁律 | 说明 |
|------|------|
| **产品外观100%一致** | 必须使用I2I图生图，产品的形状、颜色、材质、结构必须与1688原图完全一致 |
| **主图详情图逻辑分离** | 主图（1:1正方形）和详情图（3:4竖版）使用完全不同的生图逻辑，禁止混用 |
| **视觉多样化** | 11张图必须有不同的背景、角度、构图、光影，禁止全部取自同一个白底图原图 |
| **英文文案** | 所有可见文字必须是英文，禁止出现中文 |
| **无侵权元素** | 禁止出现其他品牌Logo、名人肖像、受版权保护的图案 |

### 1.2 11张图的整体结构

```
主图5张（1:1正方形，2048×2048）：
├── 01_白底清爽主图（纯白背景，产品45度角）
├── 02_真实露营场景（户外草地/森林背景）
├── 03_促销转化主图（含卖点文字+价格锚点）
├── 04_产品结构细节（侧面/俯视/特写展示结构）
└── 05_多色/多规格展示（不同颜色/尺寸并排）

详情页6张（3:4竖版，1536×2048）：
├── 06_品牌主视觉（品牌名+大场景+产品）
├── 07_核心卖点（3-4个卖点图标+文字）
├── 08_功能结构（标注线指向各部位）
├── 09_使用场景（4格拼图展示不同场景）
├── 10_产品细节（3格特写材质/工艺/配件）
└── 11_品质保障（4格服务承诺+品牌标语）
```

## 五、生图多样化落实方法

### 5.1 为什么要多样化

| 问题 | 后果 | 解决方案 |
|------|------|----------|
| 全部用白底图生成 | 11张图看起来一模一样，缺乏层次感 | 不同图片用不同参考图角度 |
| 全部用同一角度 | 无法全面展示产品 | 主图用45度，细节图用侧面/俯视 |
| 全部用纯白背景 | 视觉单调，缺乏场景感 | 场景图用户外背景，促销图用渐变背景 |
| 全部用相同光影 | 缺乏质感和层次 | 主图用柔光，细节图用侧光，场景图用自然光 |

### 5.2 11张图的多样化矩阵

| 图编号 | 参考图角度 | 背景类型 | 光影类型 | 构图方式 |
|--------|-----------|----------|----------|----------|
| 01主图 | 45度俯视角 | 纯白 | 柔和顶光 | 居中对称 |
| 02主图 | 正面微侧 | 户外草地/森林 | 自然侧光 | 偏轴+背景虚化 |
| 03主图 | 45度侧面 | 渐变背景 | 均匀柔光 | 左产品右文字 |
| 04主图 | 纯侧面/俯视 | 浅灰渐变 | 侧光突出纹理 | 居中+细节放大 |
| 05主图 | 正面 | 纯白 | 均匀柔光 | 多产品并排 |
| 06详情 | 45度+大场景 | 山脉/森林 | 自然光 | 上品牌下产品 |
| 07详情 | 侧面 | 浅灰渐变 | 均匀柔光 | 上文字下产品 |
| 08详情 | 45度全貌 | 纯白 | 均匀柔光 | 居中+标注线 |
| 09详情 | 多角度 | 4个不同场景 | 各场景自然光 | 2×2四格拼图 |

| 11详情 | 正面小图 | 浅灰渐变 | 均匀柔光 | 上文字下品牌 |

**最佳实践**：从1688产品详情页下载3-5张不同角度的图片作为I2I参考

## 六、生图质量检查清单

### 6.1 每张图生成后必须检查

| 检查项 | 合格标准 | 不合格处理 |
|--------|----------|-----------|
| 产品外观一致性 | 形状、颜色、材质、结构与原图100%一致 | 重新生成，强调"保持产品外观100%不变" |
| 文字正确性 | 所有可见文字是英文，无中文，无拼写错误 | 重新生成，明确写出正确的英文文案 |
| 背景干净度 | 无水印、无其他品牌Logo、无多余元素 | 重新生成，强调"无任何水印或多余元素" |
| 构图合理性 | 产品完整在画面内，无裁切，比例协调 | 重新生成，调整构图描述 |
| 光影自然度 | 光影方向一致，无违和感，质感真实 | 重新生成，调整光影描述 |

### 6.2 11张图整体检查

| 检查项 | 合格标准 |
|--------|----------|
| 视觉多样性 | 11张图有明显不同的背景、角度、构图、光影 |
| 信息完整性 | 覆盖了产品外观、使用场景、核心卖点、结构细节、品质保障 |
| 品牌一致性 | 所有图的品牌名、色调、风格保持一致 |
| 转化率优化 | 首图有吸引力，促销图有卖点，详情页有信任背书 |

## 七、常见问题与解决方案

### 7.1 产品外观变形

**问题**：I2I生成后产品的形状或颜色发生了变化
**解决方案**：
1. 在prompt开头强调"保持产品的形状、颜色、材质、结构100%不变"
2. 使用更高质量的参考图（清晰、无遮挡、光线好）
3. 降低生图的"创意度"，更贴近参考图
4. 如果还是变形，尝试用参考图的不同角度

### 7.2 文字乱码或拼写错误

**问题**：生成的英文文字有乱码或拼写错误
**解决方案**：
1. 在prompt中用引号明确写出正确的英文文案，如"ULTRA LIGHTWEIGHT"
2. 减少文字数量，只保留2-3个核心词
3. 使用简单常见的英文单词，避免生僻词
4. 如果还是乱码，先生成无字图，后期用PS添加文字

### 7.3 背景有多余元素

**问题**：背景中出现了不需要的人物、物品或水印
**解决方案**：
1. 在prompt中明确"背景干净，无任何多余元素"
2. 对于纯白背景图，强调"纯白色背景，无任何纹理或装饰"
3. 对于场景图，明确背景元素的范围，如"背景只有草地和天空"
4. 如果还是有多余元素，重新生成

### 7.4 11张图看起来太相似

**问题**：所有图都用了相同的背景和角度，缺乏多样性
**解决方案**：
1. 严格按照"多样化矩阵"为每张图指定不同的背景、角度、光影
2. 从1688下载多张不同角度的参考图，不同图用不同参考
3. 在prompt中明确每张图的独特之处，如"这张图用侧面视角"
4. 生成后对比检查，如果相似则重新生成
