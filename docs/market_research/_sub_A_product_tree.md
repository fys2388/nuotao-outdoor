# Nuotao Outdoor / Camping Product Tree 与候选微品类评估

> 本文件为子代理 A 产物：完整品类树（拆到微型场景/具体产品需求粒度）+ 30+ 候选微品类评估表 + 五类机会方向初步假设。
> 主市场美国，辅市场德国/欧洲；当前阶段中国直发，一人公司，低成本、Human-in-the-loop。
> 约定：推断一律标注 **INFERENCE**；不编造市场规模/销量；具体品牌仅写真实存在者。
> 配套底稿：`_SEED_BRIEF_2026.md`（35 个种子 A1–J5、排除规则、评分模型）。

## 1. 完整 Product Tree（嵌套列表，拆到微型场景粒度）

> 命名口径：每一类向下挖 2–3 层，末端是"微型场景 → 具体产品需求"。大体积主品（帐篷本体、大桌椅、大保温箱本体、电池灯具本体）仅作为"配件宿主"出现，本身排除。

### 1.1 Camping（露营本体生态）

- **Tents / Shelter 帐篷与遮蔽（配件层，不做帐篷本体）**
  - 帐篷底面保护 → 营地硬地/碎石地 → 帐篷地布 / footprint（NEW1）
  - 帐篷结构稳定 → 大风/硬地 → 反光风绳 + 调节扣 + 反光珠套装（J2）
  - 地钉五金收纳 → 出发/撤营散乱 → 地钉+锤子+拔钉器收纳小包（A10）
  - 帐篷修补 → 撕裂/开线小损坏 → 帐篷修补胶带 / 布贴修补包（无液体胶）（J1）
  - 门厅进出 → 带土进出帐篷 → 门厅地垫 / entry rug（A9）
  - 车内帐/遮阳篷固定 → 无法打钉 → 遮阳篷拉绳张力器套件（NEW15）

- **Sleeping 睡眠系统（配件层，不做充气床垫/睡袋本体）**
  - 枕头替代 → 家用枕太大 → 可压缩充气/记忆棉 camp pillow（B1）
  - 睡袋卫生/补温 → 露营洗衣难 → 薄睡袋衬里 liner（B2）
  - 睡垫携带 → 垫子太长难捆 → 睡垫捆绑带 / carry straps（A7）
  - 收纳压缩 → 睡袋/衣服体积大 → 压缩袋 / stuff sack 套装（NEW2）
  - Cot（行军床）配件 → 床面硬/蚊虫 → cot 坐垫 / 床用蚊帐
  - Hammock（吊床）配件 → 悬垂/保温/防蚊 → 悬挂绑带 + 被下隔热套 + 蚊帐（NEW3 / B3）

- **Cooking 营地厨房（工具层，避开食品接触主品）**
  - 洗碗清洁 → 无水槽 → 折叠水桶/洗脸盆（D1）
  - 厨具收纳 → 锅铲勺散乱 → 厨具卷袋 roll-up organizer（A3）
  - 备餐台面 → 野餐桌不够用 → 野餐桌上方置物架/层架（A4）
  - 手冲咖啡 → 想要咖啡不要电器 → 手冲架/法压配件（非电器）（D3）
  - 调料携带 → 小瓶漏洒 → 调料罐套装/收纳盒（NEW13）
  - 洗碗整套 → 盆+刷+晾布分开买 → 洗碗三件套 bundle（NEW14）
  - 锅具夹取 → 锅烫手拿不了 → 锅夹/防烫握把（非食品接触）

- **Lighting 照明（配件层，不做电池灯具本体）**
  - 营地灯悬挂 → 帐篷内无挂点 → 营地灯挂扣/挂带（C1）
  - 头灯损耗 → 头灯带脏旧 → 替换头灯带/收纳盒（C2）
  - 氛围灯收纳 → 串线缠结 → 串灯收纳盒 + 延长线（C3）

- **Storage 营地收纳**
  - 帐篷顶空 → 头顶空间浪费 → 帐篷顶收纳网 gear loft（A1）
  - 后备箱杂乱 → 车边帐/后备箱整理 → 模块化整理箱（A2）
  - 保温箱内部 → 饮料食物混放 → 保温箱隔板 divider（A8）
  - 椅子旁 → 杯子/手机没地方 → 椅侧收纳袋 caddy（A6）
  - 营地垃圾+照明 → 两件分开占地方 → 垃圾袋柱+灯柱二合一（A5）

- **Furniture 家具（配件层，不做大桌椅本体）**
  - 折叠椅升级 → 椅侧无杯架 → 椅侧 caddy / 杯架附件（A6）
  - 桌面临时收纳 → 桌面零碎 → 带口袋桌布 / 桌面挂袋
  - Cot 扩展 → 床边放东西 → cot 侧边小桌附件

- **Organization / Small-Space Camp Organization 小空间整理**
  - 门厅进出入 → 鞋底带泥 → 门厅地垫（A9）
  - 鞋靴晾晒 → 营地湿鞋 → 晾鞋架/晾鞋垫（J3）
  - 风绳缠绕 → 收纳乱 → 风绳卷线器
  - 五金零散 → 地钉锤子 → 五金小包（A10）

- **Comfort 营地舒适**
  - 坐/跪地面 → 地面硬/脏 → 防水压缩毛毯（B4）
  - 跪姿劳作 → 膝盖痛 → 跪垫 / 坐垫
  - 快速擦干 → 毛巾难干 → 快干超细纤维 camp towel（NEW12）

- **Hygiene 营地卫生**
  - 野外如厕 → 需要挖坑 → 便携卫生铲 + 纸套装（J4，纸为大宗白牌，只做铲）
  - 营地淋浴 → 避开水箱主品 → 淋浴喷头/挂架/水管配件（J5）
  - 洗手液站 → 无水箱 → 手动按压洗手架（不含水箱）
  - 湿巾/手纸 → 露营手持 → 壁挂式手纸/湿巾分配器

- **Accessories 杂项**
  - 帐篷修补 → 小撕裂 → 修补胶带（J1）
  - 营地工具 → 多功能刀/锯套 → 工具护套
  - 地钉拔出 → 钉太紧 → 拔钉器（integrated in A10）

### 1.2 Hiking / Day Outdoor（徒步与日间户外）

- **Hydration 饮水（配件层，滤芯主品另论）**
  - 水袋清洁 → 内胆难洗 → 水袋清洁套装 / 水管夹
  - 水瓶携带 → 手拿着累 → 水瓶 sling / 伞绳提手
- **Storage / Pack Accessories 背包收纳**
  - 背包防水 → 下雨打湿包 → 背包防雨罩 pack rain cover（NEW4）
  - 包内杂乱 → 找东西翻 → 背包收纳方块 / packing cubes（NEW11）
  - 水瓶侧袋 → 瓶子晃荡 → 侧袋固定 organizer
  - 登山杖外挂 → 无挂点 → 登山杖挂扣 / daisy chain clip
- **Comfort 徒步舒适**
  - 中途坐地 → 地面湿冷 → 闭孔泡沫坐垫 sit pad
  - 膝部保护 → 跪姿/下坡 → 徒步护膝（尺码类，INFERENCE 偏高退货，观察不优先）
- **Navigation 导航**
  - 地图保护 → 纸地图淋雨 → 防水地图袋 / map case（NEW10）
  - 指北针附属 → 挂带丢失 → 指北针挂绳/绳包
- **Organization 随身整理**
  - 小物件 → 耳机/电池/胶带 → ditty bag 小物收纳袋
  - 急救包空袋 → 卖空袋不卖内容 → 空急救包收纳袋（不含药品）
- **Weather 天气应对（配件层，不做雨衣等尺码服装）**
  - 眼镜/帽子 → 运动中掉落 → 眼镜绳 / 帽夹 leash（NEW16）
  - 鞋口进沙 → 裤脚进土 → 绑腿 gaiters（尺码类，INFERENCE 退货风险，观察）
- **Photography 徒步摄影（配件层）**
  - 相机携带 → 脖子累 → 相机肩带（避开 Peak Design  capture clip 专利结构）（I1）
  - 三脚架落地 → 软地站不稳 → 三脚架地钉脚（I2）
  - 相机防雨 → 淋雨 → 相机防雨罩 rain cover
- **Observation 观测**
  - 双筒望远镜 → 挂脖子累 → 望远镜背带 harness（I3）
  - 观鸟随身 → 镜子+手机+图鉴 → 观鸟腰袋（I4）

### 1.3 Outdoor Travel（户外旅行 / 自驾）

- **Road Trip 公路旅行**
  - 后备箱 → 行李冷藏混放 → 模块化后备箱收纳（带冷藏格）（G1）
  - 车内 → 座椅后背散乱 → 座椅背收纳袋（G3）
  - 车顶/后备箱 → 行李固定 → 行李网 / 弹力绳套装（G5）
- **Van Life 厢式露营**
  - 车窗隐私/隔热 → 晒太阳 → 车窗遮光帘（磁吸/黑色）（G2）
  - 车门蚊虫 → 开门进蚊 → 磁吸纱门/纱窗（G4）
  - 车内顶 → 顶棚空间 → 车顶收纳网
- **RV 房车**
  - 房车踏步 → 上下车带泥 → 踏步垫 / 车外地垫
  - 遮阳篷 → 风大晃动 → 遮阳篷防风拉带
  - 房车露台 → 户外地面脏 → RV 户外 patio mat（卷装，中体积）
- **Beach 海滩**
  - 坐沙 → 沙粘一身 → 防沙沙滩垫（H1）
  - 沙滩伞 → 伞被吹走 → 沙滩伞沙锚（H2）
  - 沙滩玩具 → 沙漏不干净 → 网眼沙滩玩具袋
  - 躺椅毛巾 → 风吹落 → 毛巾夹 / 躺椅夹
- **Picnic 野餐**
  - 餐具食物携带 → 散乱 → 野餐提篮 / 餐具收纳（H3）
  - 坐地 → 草地潮 → 防水底野餐毯（F3）
  - 桌子固定 → 杯瓶倒 → 野餐桌杯夹/酒瓶带
- **Portable Organization 便携整理**
  - 旅行打包 → 衣服乱 → 收纳方块套装（NEW11）
  - 洗漱 → 浴室难挂 → 悬挂洗漱包
  - 线缆 → 充电器乱 → 线缆收纳 pouch

### 1.4 Outdoor Comfort（户外舒适）

- **Seating 坐具舒适（配件层）**
  - 折叠椅侧 → 杯/手机 → 椅侧 caddy（A6）
  - 看台/草坪 → 屁股凉硬 → 体育场/看台坐垫 stadium seat（NEW5）
  - 跪姿 → 膝盖痛 → 跪垫
- **Shade 遮阳**
  - 硬地打不了钉 → 水泥/露台 → 帐篷/遮阳篷配重沙袋（NEW6）
  - 沙滩伞 → 倒伏 → 沙锚（H2）
  - 吊床遮阳 → 晒 → 吊床遮阳篷附件
  - 遮阳帆 → 固定 → 遮阳帆五金/拉绳套件
- **Cooling 降温（无电池）**
  - 高温出汗 → 脖子热 → 超细纤维降温毛巾（NEW7）
  - 手动喷水 → 要电池 → 手动喷雾瓶（无电池款，观察）
- **Insect Control 防虫（不做化学驱蚊剂本体）**
  - 吊床/床 → 蚊虫 → 蚊帐（integrated B3/NEW3）
  - 车门 → 进蚊 → 磁吸纱门（G4）
- **Sleeping Comfort 睡眠舒适**
  - 枕头 → 家枕大 → camp pillow（B1）
  - 床面硬 → 硌 → cot 垫 / 睡垫保温层
- **Organization 舒适场景整理**
  - 躺椅旁 → 置物 → 边几 / caddy

### 1.5 Outdoor Hobby / Nature（户外爱好与自然）

- **Birding 观鸟**
  - 望远镜携带 → 脖子累 → harness（I3）
  - 随身小物 → 镜子+手机+本 → 观鸟腰袋（I4）
  - 图鉴 → 翻找 → 图鉴固定套
- **Fishing Accessories 钓鱼配件（不做竿轮主品）**
  - 钓竿携带 → 车内刮擦 → 钓竿绑带/固定带
  - 小配件 → 钩铅坠散乱 → 钓鱼小物盒（箱式，中体积观察）
- **Wildlife Observation 野生动物观测**
  - 追踪相机 → 被盗/晃动 → 相机绑带/锁盒（不含相机本体）
- **Photography 户外摄影**
  - 相机携带 → 脖子累 → 相机肩带（避开 capture clip 专利）（I1）
  - 三脚架 → 软地 → 地钉脚（I2）
  - 相机包 → 内胆保护 → 相机包内胆 insert
- **Astronomy 天文（避电池/化学）**
  - 星图 → 手持 → 旋转星图 planisphere（纸质，低毛利观察）
- **Nature Education 自然教育（避儿童安全装备）**
  - 野外记录 → 纸本湿 → 防水笔记本（NEW10）
  - 昆虫观察 → 儿童玩具安全 → 观察盒/放大镜（CPSIA 警告，谨慎）

### 1.6 Pet Outdoor（宠物户外）

- **Camping with Dogs 携犬露营**
  - 犬饮水 → 无水碗 → 折叠狗水碗（E1）
  - 犬休息 → 硬地 → 便携狗垫/狗毯（E2）
  - 犬活动范围 → 乱跑 → 犬牵引缆/地桩 runner（NEW9）
  - 犬牵引 → 桩打不进 → 螺旋地钉
- **Hiking with Dogs 携犬徒步**
  - 拾便 → 手持麻烦 → 屎袋分配器（E4，袋为白牌大宗，只做器）
  - 急救 → 空袋 → 空狗急救包袋（不含药品）
- **Vehicle Outdoor Pet 车载宠物**
  - 车内防脏 → 狗毛/爪痕 → 车载狗垫/后座 hammock（NEW8）
  - 犬乘车安全 → 急刹 —— **狗安全带/车载 harness（E3）：法规/责任风险，排除，见 §2**
- **Outdoor Pet Comfort 宠物舒适**
  - 降温 → 狗怕热 → 狗降温垫（观察，避凝胶化学主品）
  - 车座 → 防水 → 车载狗垫（NEW8）

### 1.7 Family / Kids Outdoor（家庭与儿童户外，避开儿童安全装备）

- **Family Camping 家庭露营**
  - 全家厨房 → 厨具多 → 家庭厨具提篮 caddy（F2）
  - 帐篷顶 → 全家小物 → 大号 gear loft（A1 放大版）
  - 进出 → 带泥 → 门厅地垫（A9）
- **Children's Equipment 儿童装备（避儿童安全主品）**
  - 儿童随身 → 自己的东西 → 儿童露营小背包/收纳（F1，CPSIA 警告）
  - 儿童探索 → 观察昆虫 → 儿童探索盒（CPSIA 小零件/铅含量警告，谨慎）
- **Organization 家庭整理**
  - 全家打包 → 行李多 → 家庭收纳方块（NEW11）
  - 营地玩具 → 沙/草 → 网眼玩具袋
- **Safety 安全（原则性排除）**
  - 儿童安全装备、儿童夜灯（电池）、化学荧光棒 —— **整体排除**（法规/电池/化学风险）

## 3. 五类机会方向的初步假设（供 B/C/D/E 子代理验证，非结论）

### 方向 1：被忽视的小场景（某个非常具体的 camping situation）
- **硬地/露台无法打地钉** → 帐篷/遮阳篷配重沙袋（NEW6），目前地钉方案在水泥地完全失效。
- **后备箱冷藏与杂物混放串味难取** → 带冷藏格的模块化收纳（G1）+ 保温箱隔板（A8）组合。
- **帐篷门厅死空间** → gear loft（A1）+ 门厅地垫（A9）+ 晾鞋垫（J3）组成"门厅系统"，目前没人整套卖。
- **营地垃圾与照明各占一地** → 垃圾袋柱 + 灯柱二合一（A5）。
- **观鸟随身小物（镜子/手机/图鉴）无专用包** → 观鸟腰袋（I4），人群精准但配件稀少。

### 方向 2：现有产品体验差（太重/难收/占空间/难洗/难携/难整理）
- **折叠桶又软又晃** → 带刚性桶口的折叠水桶（D1），解决软塌变形痛点。
- **营地灯无处挂** → 通用挂扣/挂带（C1），存量灯都缺挂点。
- **保温箱内食物饮料混放** → 可裁剪隔板（A8），比换大箱便宜。
- **睡垫太长难捆、背包肩带滑动** → 替换捆绑带（A7），耗材化。
- **椅子侧没地方放杯/手机/遥控器** → 椅侧 caddy（A6），折叠椅的通用痛点。

### 方向 3：多产品整合为一（Product A + B + C 合并）
- 垃圾袋柱 + 灯柱 = A5。
- 后备箱收纳 + 冷藏格 = G1。
- 折叠洗碗盆 + 刷洗 + 晾布 = NEW14（洗碗三件套）。
- 厨具卷袋（A3）+ 砧板套筒 + 调料盒（NEW13）= "营地厨房 roll-up 整套"。
- 狗水碗（E1）+ 屎袋分配器（E4）+ 地桩（NEW9）= "携犬露营配件包"。

### 方向 4：Outdoor × 其他场景（Travel / Car / Pet / Family / Home / Photo / Beach / RV / Van）
- **Outdoor × Van/Car**：磁吸纱窗（G4）+ 车窗遮光帘（G2）+ 后备箱收纳（G1）= 车内露营三件套。
- **Outdoor × Pet**：车载狗垫（NEW8）+ 折叠狗碗（E1）+ 牵引缆（NEW9）。
- **Outdoor × Beach**：防沙垫（H1）+ 沙锚（H2）+ 野餐提篮（H3）。
- **Outdoor × Photo/Birding**：望远镜 harness（I3）+ 三脚架地钉（I2）+ 相机肩带（避开 capture clip）。
- **Outdoor × Family**：儿童收纳包（F1）+ 家庭厨具提篮（F2）+ 防水野餐毯（F3）。

### 方向 5：Accessory > Big Gear（配件、收纳、舒适、升级、保护）
- **不做帐篷本体**：做地布（NEW1）+ 风绳套装（J2）+ 修补胶带（J1）+ gear loft（A1）。
- **不做大保温箱本体**：做隔板（A8）+ 提带/篮 + 冷藏格收纳（G1）。
- **不做大桌椅本体**：做椅侧 caddy（A6）+ 桌上层架（A4）+ 坐垫（NEW5）。
- **不做大背包本体**：做防雨罩（NEW4）+ 收纳方块（NEW11）+ 登山杖挂扣。
- **不做大床/睡袋本体**：做枕头（B1）+ 衬里（B2）+ 压缩袋（NEW2）+ 垫绑带（A7）。
