X = Repeat Rate（高复购在右）｜Y = Regulation Risk（高法规风险在上）｜右上红区 = 高复购但法规阻断，应 EXCLUDE。
读图说明：本图 33 个微品类。红色阴影区（右上）= 高复购但法规阻断：Seam Grip（UN1133 Class 3）、DWR Aerosol（DOT Div 2.2 + EPA）、Lithium Battery（49 CFR 173.185）、Butane Fuel（DOT Div 2.1）、Water Purification Tablets（EPA FIFRA）、Triple-Antibiotic First Aid（21 CFR 333）、Lighter（UN1057）、Dog Car Harness（FMVSS 213）。绿色点（右下/左下）= 普货，中国直发友好。
核心结论：Nuotao 第一批全部落在绿色区（Repair Tape / Shock Cord / Buckles / Zipper Pull / Guyline / Chair Feet），法规风险 ≤3/10；液体胶与气雾剂即便复购再高也 EXCLUDE，走海外仓或不做。
使用建议：法规风险 ≤3 的品类可中国直发；4–6 分（食品接触/宠物扣/tackle）需测试报告；≥7 分一律走海外仓或 EXCLUDE。Seam Grip 虽复购强，但 UN1133 Class 3 液体不直发。
