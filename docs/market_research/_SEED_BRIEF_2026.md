# Nuotao DTC Outdoor 微品类机会调研 — 种子清单与工作约定

> 本文件是 6 个并行子代理共享的工作底稿。所有子代理必须先读本文件再开干。
> 真实性 > 完整性 > 美观。拿不到的数据写 UNKNOWN；推断写 INFERENCE；第三方估算必须标机构+日期+口径。
> 任何数字/事实必须带 URL + 日期，禁止编造。

## 0. 项目背景（一句话）
Nuotao Outdoor = 中国卖家主导的 DTC 户外露营独立站，主市场美国，辅市场德国/欧洲；中国直发阶段优先；一人公司，低成本切入，Human-in-the-loop。

## 1. 必须排除的品类（即便销量大也不碰）
- 鞋服尺码类（高退货）
- 安全装备、儿童安全、电池、高功率电子、食品接触、医疗（高法规）
- 大体积帐篷、大型桌椅、大型储物、充气大件（高物流成本）
- 复杂电子、电池产品（高售后）
- 明显品牌仿品、IP 图案、专利风险明显产品（高侵权）
- 白牌已严重价格战、Amazon 首屏品牌垄断、无法差异化的品类

## 2. 五类重点机会方向（主动搜索验证，不要预设结论）
1. 被忽视的小场景（某个非常具体的 camping situation）
2. 现有产品体验差（太重 / 难收 / 占空间 / 难洗 / 难装 / 难携 / 不耐用 / 难整理）
3. 多产品整合为一（Product A + B + C 合并）
4. Outdoor × 其他场景（Travel / Car / Pet / Family / Home / Photography / Fishing / Beach / RV / Van Life）
5. Accessory > Big Gear（配件、收纳、舒适、升级、保护；小、轻、低库存、易组合）

## 3. 候选微品类种子清单（35 个，按大类分组；子代理 B/C/D/E/F 从这里面挑真实数据采集）

### A. Camping Organization / Storage / 收纳配件
- A1. Tent gear loft / hanging organizer（帐篷顶收纳网）
- A2. Camping storage bin 模块化整理箱（车边帐/后备箱）
- A3. Cookware/utensil roll-up organizer（厨具卷袋）
- A4. Camp kitchen table organizer / shelf（野餐桌上方置物架）
- A5. Trash bag + lantern post 二合一（营地垃圾袋柱）
- A6. Camp chair side organizer / caddy（椅侧收纳袋）
- A7. Sleeping pad roll straps / carry straps（睡垫捆绑带）
- A8. Cooler partition / divider（保温箱隔板）
- A9. Campsite mat / entry rug（帐篷门厅地垫）
- A10. Peg/mallet/tent accessory pouch（地钉锤子小包）

### B. Comfort / Sleeping 周边
- B1. Camp pillow 可压缩充气/记忆棉（重点：体积小、轻、退货低）
- B2. Sleeping bag liner / 薄衬（旅行/露营通用）
- B3. Cot / hammock accessory（蚊帐、雨棚、坐垫）
- B4. Camp blanket 防水压缩毛毯（野餐/营地/车用）
- B5. Neck pillow / travel pillow（车/飞机/露营通用）

### C. Lighting 周边（非电池主品，聚焦配件/手动/CR123 小电筒周边）
- C1. Lantern hanging strap / hook（营地灯挂扣）
- C2. Headlamp 配件（替换带、收纳盒）
- C3. Camping string light 收纳盒 + 延长线

### D. Cooking / Food Prep 周边（避开食品接触主品，聚焦工具类）
- D1. Collapsible bucket / wash basin（折叠水桶/洗脸盆）
- D2. Camping cutting board / utensil set（可折叠砧板刀具套装）
- D3. Coffee pour-over / French press camping accessory（露营咖啡配件，非电器）
- D4. Reusable camping food bag / silicone bag（硅胶食品袋，注意食品接触合规）

### E. Outdoor × Pet（狗露营/徒步配件）
- E1. Portable dog water bowl（折叠狗水碗）
- E2. Dog camping bed / blanket（便携狗垫）
- E3. Dog seatbelt / car harness（车宠安全，注意法规）
- E4. Dog poop bag dispenser / holder（屎袋分配器）

### F. Outdoor × Family / Kids（避开儿童安全装备）
- F1. Kids camping organizer / backpack（儿童露营小背包）
- F2. Family camp kitchen caddy（家庭厨具提篮）
- F3. Outdoor blanket / picnic blanket（带防水底的野餐毯）

### G. Outdoor × Car / Van / Roadtrip
- G1. Car trunk organizer 模块化（带冷藏格）
- G2. Window shade / car camper window cover（车窗遮光帘）
- G3. Car seat back organizer（座椅背收纳）
- G4. Magnetic screen door / window bug net（磁吸纱门/纱窗）

### H. Outdoor × Beach / Picnic
- H1. Sand-free beach mat / sand-proof blanket（防沙沙滩垫）
- H2. Beach umbrella anchor / sand anchor（沙滩伞固定桩）

### I. Outdoor × Photography / Observation
