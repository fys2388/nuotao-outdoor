## 四、打样计划（任务书第 16 节）

### 供应商打样（首批 2-3 家）
1. **潮州英迪钛业（SNOW ROCK）**——超级工厂，定制开模，100 件起，¥67.75，月产能 5000+
2. **潮州顾家五金**——ODM/贴牌 500-1000 件，来样/来图，开票 12%
3. **揭阳钛帮手**——1 件起定（样品友好），¥10-130

### 打样 QC（采购前必测）
1. 材料成分（光谱 TA1/TA2 牌号）→ SGS/TUV
2. 厚度卡尺（0.3/0.4/0.5mm）
3. 实际称重（单锅/套装/含包装）
4. 容量（满水）+ 内径（容 230g 罐）
5. 锅盖扣合/密封测试
6. 手柄强度 + 防烫管
7. 热源兼容性（气炉/酒精炉——**禁止默认兼容所有**）
8. 包装跌落测试
9. 食品接触迁移测试（EN 13130/CoE 法，3% 乙酸）

### 到岸报价（打样时必取）
- 潮州英迪/顾家 → 美国 DDP / 欧盟 DDP **真实运费 + 税率**
- 确认体积重 + 最低计费重（金属炊具小件可能按体积重）
- **未获真实报价前，到岸成本 = UNKNOWN**

## 五、上线策略（任务书第 22 节）

1. **优先欧盟/英国**（Base 12.8%，€3 固定关税 + IOSS，关税友好）或美国定价 **≥$54.95 走 DDP 专线**
2. **30-60 天 DTC 落地页测试**（欧盟/英国），验证 AOV/转化/退货
3. **不做第一 Hero 主打**——复购弱；作为**高客单获客款 + 配件生态**
4. 首批发货：Solo Set + 2-Person Set + 配件 Bundle（3 SKU，打样验证后小批量）
