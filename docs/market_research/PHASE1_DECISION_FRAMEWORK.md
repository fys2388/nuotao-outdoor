# Nuotao Outdoor Phase 1 产品组合决策框架

> **状态**: PENDING — 等待 6 个子代理 Customer Journey 研究结果

---

## 决策框架

### 评估维度 (10 维)

| 维度 | 权重 | 问题 |
|------|------|------|
| **D1: 第一单触发** | 15% | 客户为什么买第一单？触发是否明确？ |
| **D2: 第二单证据** | 20% | 有没有真实证据证明客户会买第二单？ |
| **D3: 复购机制** | 15% | 第二单是同品复购/配件/替换/维护/升级/捆绑/新场景？ |
| **D4: 时间间隔** | 10% | 第二单大概多久发生？1周/1月/1季/1年？ |
| **D5: 客户回来概率** | 15% | 客户回来买 Nuotao 而不是原品牌/Amazon 的概率？ |
| **D6: 品牌壁垒** | 10% | 头部品牌的客户忠诚度多高？Nuotao 能切入吗？ |
| **D7: 产品生态密度** | 5% | 围绕这个产品有多少配件/替换件可卖？ |
| **D8: 供应链确定性** | 5% | 1688 供应链是否成熟？质量是否可控？ |
| **D9: 内容/SEO 潜力** | 5% | 是否有足够的内容素材和搜索需求？ |
| **D10: 法规风险** | 5% | 是否有监管障碍？ |

### 评分标准

| 分数 | 含义 |
|------|------|
| 10 | 有强证据支持，确定可行 |
| 8 | 有中等证据，大概率可行 |
| 6 | 有弱证据或推断，可能可行 |
| 4 | 证据不足，需进一步验证 |
| 2 | 有反面证据，可能不可行 |
| 0 | 有强反面证据，不可行 |
| UNKNOWN | 无数据 |

### 决策阈值

| 总分 | 决策 |
|------|------|
| ≥ 80 | ✅ GO — 确定值得投入 |
| 60-79 | ⚠️ CONDITIONAL — 有条件投入 (需验证某条件) |
| 40-59 | ⚠️ CONDITIONAL — 高风险，小规模测试 |
| < 40 | ❌ NO-GO — 不值得投入 |
