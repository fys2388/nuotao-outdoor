## 2. 完整 Outdoor/Camping Product Tree

> 搬运自 Sub A 产物。末端为 "微型场景 → 具体产品需求"。大体积主品（帐篷本体 / 大桌椅 / 大保温箱 / 电池灯具本体）仅作为配件宿主出现，本身排除。

### 2.1 Camping（露营本体生态）



* **Tents/Shelter 配件**：帐篷地布 footprint / 反光风绳 + 调节扣 + 反光珠套装 / 地钉锤子收纳小包 / 帐篷修补胶带（无液体胶） / 门厅地垫 entry rug / 遮阳篷拉绳张力器套件

* **Sleeping 配件**：可压缩 camp pillow / 薄睡袋衬里 liner / 睡垫捆绑带 carry straps / 压缩袋 stuff sack 套装 /cot 坐垫 + 蚊帐 / 吊床悬挂绑带 + 被下隔热套 + 蚊帐

* **Cooking 工具**：折叠水桶 / 洗脸盆 / 厨具卷袋 roll-up / 野餐桌上方置物架 / 手冲咖啡配件（非电器） / 调料罐套装 / 洗碗三件套 bundle / 锅夹防烫握把

* **Lighting 配件**：营地灯挂扣 / 挂带 / 头灯替换带 + 收纳盒 / 串灯收纳盒 + 延长线

* **Storage**：帐篷顶收纳网 gear loft / 模块化整理箱 / 保温箱隔板 divider / 椅侧收纳袋 caddy / 垃圾袋柱 + 灯柱二合一

* **Furniture 配件**：椅侧 caddy / 桌面临时挂袋 /cot 侧边小桌

* **Organization**：门厅地垫 / 晾鞋架 / 风绳卷线器 / 五金小包

* **Comfort**：防水压缩毛毯 / 跪垫 / 快干超细纤维 camp towel

* **Hygiene**：便携卫生铲（不含大宗纸） / 淋浴喷头挂架配件 / 手动按压洗手架 / 壁挂手纸分配器

### 2.2 Hiking / Day Outdoor



* **Hydration 配件**：水袋清洁套装 / 水瓶 sling 提手

* **Pack 配件**：背包防雨罩 / 背包收纳方块 packing cubes / 侧袋固定 organizer / 登山杖挂扣

* **Comfort**：闭孔泡沫坐垫 sit pad / 护膝（尺码类，观察）

* **Navigation**：防水地图袋 map case / 指北针挂绳

* **Organization**：ditty bag 小物袋 / 空急救包收纳袋

* **Weather 配件**：眼镜绳 / 帽夹 leash / 绑腿 gaiters（尺码类，观察）

* **Photography**：相机肩带（避开 capture clip 专利） / 三脚架地钉脚 / 相机防雨罩

* **Observation**：望远镜背带 harness / 观鸟腰袋

### 2.3 Outdoor Travel（自驾 / 公路 / Van/Beach/Picnic）



* **Road Trip**：模块化后备箱收纳（带冷藏格） / 座椅背收纳袋 / 行李网弹力绳套装

* **Van Life**：车窗遮光帘 / 磁吸纱门纱窗 / 车顶收纳网

* **RV**：踏步垫 / 遮阳篷防风拉带 / RV 户外 patio mat

* **Beach**：防沙沙滩垫 / 沙滩伞沙锚 / 网眼沙滩玩具袋 / 躺椅毛巾夹

* **Picnic**：野餐提篮餐具收纳 / 防水底野餐毯 / 野餐桌杯夹

* **Portable**：收纳方块套装 / 悬挂洗漱包 / 线缆收纳 pouch

### 2.4 Outdoor Comfort



* **Seating**：椅侧 caddy / 体育场看台坐垫 / 跪垫

* **Shade**：帐篷配重沙袋（空袋发货） / 沙锚 / 吊床遮阳篷 / 遮阳帆五金套件

* **Cooling（无电池）**：超细纤维降温毛巾 / 手动喷雾瓶

* **Insect Control**：蚊帐 / 磁吸纱门

* **Sleeping**：camp pillow /cot 垫

### 2.5 Outdoor Hobby / Nature



* **Birding**：望远镜 harness / 观鸟腰袋 / 图鉴固定套

* **Fishing 配件**：钓竿绑带 / 钓鱼小物盒

* **Photography**：相机肩带 / 三脚架地钉脚 / 相机包内胆 insert

* **Astronomy**：旋转星图（纸质，低毛利观察）

* **Nature Education**：防水笔记本 / 昆虫观察盒（CPSIA 警告，谨慎）

### 2.6 Pet Outdoor



* **Camping with Dogs**：折叠狗水碗 / 便携狗垫 / 狗睡袋 / 犬牵引缆 + 螺旋地桩 runner

* **Hiking with Dogs**：屎袋分配器（袋为白牌只做器） / 空狗急救包袋

* **Vehicle Pet**：车载狗垫 / 后座 hammock

* **Excluded**：狗安全带 / 车载 harness（E3，安全装备排除）

### 2.7 Family / Kids Outdoor



* **Family Camping**：家庭厨具提篮 / 大号 gear loft / 门厅地垫

* **Kids（排除 CPSIA 高风险）**：儿童露营背包（F1，触发 CPSIA + CPC，文案禁用 kids 定位）

* **Organization**：家庭收纳方块 / 网眼玩具袋

### R1.5 第三步交叉验证结论

1. **更便宜但质量不降级的供应商**：
   - B1：¥15.50 入门款存在（浙江夏诺多吉同款 ¥42 是品牌款），但带绒面外套的定制款只有宁波绿山 ¥19.95 这个价位靠谱，再低就要用 PVC 植绒（上轮痛点明确说吵/滑）。
   - E2：武义山姆 ¥17.1 是目前找到的最低月销款，但钢管粗细/网布克重未验证，需索样。
   - E4：¥0.25 骨头款已是白牌红海，不能做；差异化方向是硅胶多色（宁波乐玛）或可降解补充装（义乌泽跃）。

2. **现成模具 vs 开模**：
   - B1 横向气仓：现有奶酪枕是竖纹/普通气仓，横向气仓可能需改模具，需向宁波绿山确认模具费（预估 ¥5000-20000 [ESTIMATE]，未证实）。
   - D1 硬 PP 桶底：布艺折叠盆是现成的，硬底需重新注塑，大概率开模。
   - G1 模块化分隔：现有产品多为固定格，模块化分隔需改模具。

3. **MOQ 压到 100-300 件测款**：
   - 1688 大多数现货款 MOQ = 1-2 件（一件代发），但 OEM/定制色/定制 LOGO 通常 500-1000 件起。
   - [INFERENCE] 测款策略：先按现货款（无定制）100 件代发测市场反应，验证通过再谈 OEM 定制。

4. **认证配合意愿**：
   - 宁波绿山 9 年厂、浙江派泰乐 16 年厂、徐州尚欧 8 年厂——这些有跨境经验的厂通常能配合 REACH DoC / FTC 纺织标签 / Prop 65 声明，但需旺旺确认。
