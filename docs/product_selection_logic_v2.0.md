### 维度3：全成本利润率（15%）⭐ V2.0升级

**计算公式**：
```
全成本利润率 = (售价USD × 7.2 - 采购价CNY - 国际物流费CNY - 平台费CNY - 营销费CNY) / (售价USD × 7.2) × 100%
```

**成本项说明**：
- 国际物流费：按重量估算（首重¥80/kg + 续重¥30/kg）
- 平台费：WooCommerce无平台费，Stripe支付手续费2.9%+$0.30
- 营销费：按售价15%估算（Facebook/Google广告）
- 汇率：1 USD = 7.2 CNY

| 评分 | 全成本利润率 |
|------|-------------|
| 90-100 | >70% |
| 80-89 | 60-70% |
| 70-79 | 50-60% |
| 60-69 | 40-50% |
| <60 | <40% |

**示例计算（折叠月亮椅）**：
- 售价：$39.99 × 7.2 = ¥287.93
- 采购价：¥40.88
- 国际物流费：2.5kg × ¥80 = ¥200（首重）→ 实际约¥120（专线折扣）
- 平台费：¥287.93 × 2.9% + ¥2.16 = ¥10.51
- 营销费：¥287.93 × 15% = ¥43.19
- 总成本：¥40.88 + ¥120 + ¥10.51 + ¥43.19 = ¥214.58
- 利润：¥287.93 - ¥214.58 = ¥73.35
- 全成本利润率：¥73.35 / ¥287.93 = **25.5%**（偏低，需优化物流或提价）

> ⚠️ 注意：国际物流是最大成本项，轻小件产品（<1kg）利润率显著高于重件产品。

- **Q1（1-3月）**：冬季露营、滑雪装备、室内户外（低迷期）

- **Q3（7-9月）**：夏季露营、钓鱼、水上运动（高峰期）
- **Q4（10-12月）**：秋季露营、万圣节、黑五、圣诞购物季（高峰期+礼品季）

| 评分 | 标准 |
|------|------|

| 70-79 | 旺季持续2个月，当前处于平季 |
| 60-69 | 旺季仅1个月，当前处于淡季 |

**上架时机策略**：

- 全年热销产品随时可上架

### 维度10：AI生图难度（5%）⭐ V2.0新增

**评估维度**：
- 产品结构复杂度（简单/中等/复杂）
- 材质表现难度（金属反光/织物纹理/透明材质）
- 细节还原要求（Logo/按钮/接口/缝线）
- I2I参考图质量（角度/光线/背景）

| 评分 | 标准（生图越容易分越高） |
|------|------------------------|
| 90-100 | 结构简单（如收纳袋/水壶），材质单一，I2I参考图质量高，生图成功率>90% |
| 80-89 | 结构较简单（如折叠椅/桌子），材质2-3种，生图成功率80-90% |
| 70-79 | 结构中等（如炉具/头灯），有金属反光和小细节，生图成功率70-80% |
| 60-69 | 结构复杂（如帐篷/背包），多材质多细节，生图成功率60-70% |
| <60 | 结构极复杂（如电子设备/精密仪器），有大量文字/按钮/接口，生图成功率<60% |

**生图难度应对策略**：
- 高难度产品：增加I2I参考图数量（多角度），降低生图预期，优先保证主图质量
- 中等难度产品：标准5主图+6详情页流程
- 低难度产品：可尝试更创意的场景和构图

### 维度11：合规与侵权风险（5%）⭐ V2.0新增

## 四、选品操作流程（V2.0完整版，10步）

```
Step 1: 品类规划 → 基于7大系列和季节性，确定本期选品方向
Step 2: 1688搜索 → 关键词搜索，按销量排序，浏览前20个产品
Step 3: 初步筛选 → 6维度快速评分（供应商/销量/利润/质量/物流/差异化），≥70分进入下一轮
Step 4: 数据核查 → Google Trends热度 + 亚马逊竞争度 + 季节性评估
Step 5: 合规核查 → 专利/商标/认证/材质/标签风险评估
Step 6: 生图难度评估 → 产品结构复杂度 + I2I参考图质量
Step 7: 全成本利润测算 → 采购价+物流+平台费+营销费，计算全成本利润率
Step 8: 11维度综合评分 → 加权计算总分，确定A/B/C/D级
Step 9: 产品信息采集 → Offer ID、价格、供应商、主图URL、规格参数、多图参考
Step 10: 导入系统 → 录入Nuotao系统，标记candidate_status和评分等级
```

## 七、V2.0选品逻辑的关键变化

### 7.1 从"凭感觉"到"数据驱动"
- V1.0：主要靠人工判断供应商和销量
- V2.0：新增Google Trends、亚马逊竞争度、季节性等外部数据

### 7.2 从"采购价利润率"到"全成本利润率"
- V1.0：利润率 = (售价 - 采购价) / 售价，虚高
- V2.0：计入国际物流、平台费、营销费，反映真实盈利能力

### 7.3 从"能生图就行"到"生图难度评估"
- V1.0：默认所有产品都能AI生图
- V2.0：评估生图难度，高难度产品调整生图策略

### 7.4 从"无合规意识"到"合规风险前置"
- V1.0：未考虑专利/认证风险
- V2.0：选品阶段即核查合规风险，避免后期侵权纠纷

### 7.5 从"随时上架"到"季节性时机选择"
- V1.0：选品后立即上架
- V2.0：考虑季节性，提前1-2个月上架旺季产品

### 9.1 权重合计缺口（95% vs 100%）

| 组 | 维度 | 文档权重 |
|---|---|---|
| V1.0 保留 | 供应商资质 15% + 销量验证 10% + 全成本利润率 15% + 产品质量 10% + 物流支持 5% + 差异化空间 5% | 60% |
| V2.0 新增 | 市场热度 10% + 亚马逊竞争度 10% + 季节性 5% + AI生图难度 5% + 合规与侵权 5% | 35% |
| **合计** | | **95%** |

- **问题**：11 维逐项相加 = 95%，与评分总表"合计 100%"不符，差 5 个百分点。
- **推荐修正（待总负责人确认后生效）**：市场热度 10% → **15%**（V2.0 新增维度中最核心的数据驱动项，与"引入 Google Trends/TikTok 数据"的升级目标一致）。修正后：V2.0 新增组 = 40%，合计 = 100%，闭环。
- **备选修正**：亚马逊竞争度 10% → 15%（若认为竞争度权重应高于热度）。
- **修正生效前**：本批次评分仍按文档原权重计算（合计 95%），修正后需重算并同步更新总览文档。

### 9.2 示例加权总分与明细不符
