## 2. 工具注册与配置步骤

### 2.1 ChatGPT / Claude / Gemini（脚本生成）

**推荐优先级：** Claude > ChatGPT > Gemini

#### Claude（推荐）
1. 访问 https://claude.ai
2. 用 Google 账号或邮箱注册
3. 免费版即可使用 Claude 3.5 Sonnet
4. **配置提示词**：在对话开头设置角色
   ```
   Role: You are a TikTok/Reels content strategist for Nuotao Outdoor, 
   an outdoor gear DTC brand. You write engaging, conversion-focused 
   short video scripts in English.
   Rules:
   - Hook in first 3 seconds
   - Casual, adventurous tone
   - Include visual descriptions for each segment
   - End with clear CTA
   - 30-60 seconds duration
   ```

#### ChatGPT
1. 访问 https://chat.openai.com
2. 注册账号（需手机号验证）
3. 免费版使用 GPT-3.5，足够脚本生成
4. 可保存自定义 GPT（需 Plus）

#### Google Gemini
1. 访问 https://gemini.google.com
2. 用 Google 账号登录
3. 免费版使用 Gemini 1.5 Flash
4. 优势：可直接搜索最新趋势

### 2.2 Microsoft Copilot（AI 图片，DALL-E 3）

1. 访问 https://copilot.microsoft.com
2. 用 Microsoft 账号登录（Outlook/Hotmail）
3. 免费使用 DALL-E 3 生成图片
4. **每天额度**：约15张图片（重置时间不固定）
5. **使用技巧**：
   - 用英文提示词效果更好
   - 生成场景背景图，不要直接生成产品（产品用真实图）
   - 提示词模板见 `ai_prompt_library.md`

### 2.3 豆包（AI 图片，备用）

1. 访问 https://www.doubao.com
2. 用手机号注册
3. 免费使用图片生成
4. **优势**：中文提示词友好，国内访问稳定
5. **用途**：Copilot 额度用完时的备用

### 2.4 Pika（AI 视频生成）

1. 访问 https://pika.art
2. 用 Google 账号或 Discord 登录
3. **免费额度**：每天4次生成（重置时间约UTC 0点）
4. **配置**：
   - 选择 16:9 或 9:16 比例（短视频用 9:16）
   - Motion 调节：0.5-0.7（避免过度运动）
   - 负向提示词：`blurry, low quality, distorted, watermark, text`
5. **使用技巧**：
   - 图生视频：上传产品图/场景图，生成动态效果
   - 文生视频：生成户外空镜（森林、营地、徒步）
   - 生成后可下载 MP4，导入 CapCut 剪辑

### 2.5 Luma Dream Machine（AI 视频生成，备用）

1. 访问 https://lumalabs.ai/dream-machine
2. 用 Google 账号注册
3. **免费额度**：每月4次生成（月初重置）
4. **优势**：视频质量高，运动自然
5. **用途**：Pika 额度用完时的备用，或需要高质量场景时

### 2.6 ElevenLabs（AI 配音）

1. 访问 https://elevenlabs.io
2. 用 Google 账号或邮箱注册
3. **免费额度**：每月10分钟语音生成
4. **配置**：
   - **推荐音色**：
     - 男声：`Adam`（沉稳，适合户外）、`Antoni`（年轻活力）
     - 女声：`Rachel`（自然亲切）、`Domi`（活力）
   - **稳定性（Stability）**：0.5-0.7（太高会机械，太低会飘）
   - **相似度（Similarity）**：0.8-0.9
   - **风格夸张（Style Exaggeration）**：0.3-0.5（户外类可稍高）
5. **使用技巧**：
   - 脚本分段生成（每段15-30秒），避免一次性太长
   - 生成后试听，不满意可重新生成（不额外消耗额度？实际会消耗，建议一次调好参数）
   - 下载 MP3 格式，导入 CapCut
6. **额度计算**：10分钟/月 ≈ 20条30秒视频（够用）

### 2.7 Suno（AI 音乐）

1. 访问 https://suno.com
2. 用 Google 账号或 Discord 登录
3. **免费额度**：每天5首歌曲（重置时间约UTC 0点）
4. **使用技巧**：
   - 生成纯音乐（Instrumental）作为背景音乐
   - 提示词示例：`upbeat acoustic guitar, adventure vibe, outdoor, no lyrics, 120bpm`
   - 选择 2-3 分钟版本，剪辑时截取片段
5. **替代方案**：CapCut 内置音乐库完全免费，且可商用，优先使用

### 2.8 CapCut（剪辑/字幕/特效，核心工具）

1. **下载**：访问 https://www.capcut.com 下载桌面版（Windows/Mac）
   - 或使用网页版：https://www.capcut.com/editor
2. **登录**：用 Google/TikTok/邮箱账号登录（免费）
3. **核心功能配置**：
   - **自动字幕**：导入音频/视频 → 文本 → 自动字幕 → 选择英语 → 生成
     - 字幕样式：字体选 `Montserrat` 或 `Bebas Neue`，大小 8-10，加黑色描边
   - **智能抠图**：选中图片 → 抠图 → 自动抠图（免费，效果好）
   - **模板**：模板库搜索 `outdoor`、`travel`、`product`，可直接套用
   - **关键帧动画**：图片缩放/平移（Ken Burns 效果），让静态图动起来
   - **转场**：推荐 `叠化`、`模糊`、`缩放`，避免花哨转场
   - **调色**：滤镜选 `清新`、`自然`、`电影感`，户外类适当提高饱和度和对比度
4. **批量生产技巧**：
   - 做1套精品模板（片头+字幕样式+转场+片尾），保存为草稿
   - 之后每条视频只换素材和配音，10分钟出一条
   - 使用「批量修改」功能统一调整字幕样式

### 2.9 免费素材库

#### Pexels（视频+图片）
- 网址：https://www.pexels.com
- 免费商用，无需署名
- 搜索关键词：`camping`、`hiking`、`outdoor`、`forest`、`tent`、`backpack`
- 视频可直接下载 MP4

#### Pixabay（视频+图片+音乐）
- 网址：https://pixabay.com
- 免费商用
- 优势：音乐素材多

#### Unsplash（图片）
- 网址：https://unsplash.com
- 免费商用
- 高质量户外摄影图

## 3. 工具协作流程

### 3.1 单条视频生产流程（AI 全流程）

```
┌─────────────────────────────────────────────────────────────┐
│  1. 选题 & 脚本（ChatGPT/Claude）                            │
│     └─ 生成 30-60 秒脚本，含分镜和视觉描述                    │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 素材准备                                                  │
│     ├─ 产品图：从网站产品库下载（已有30 SKU × 11张图）       │
│     ├─ 场景图：Copilot/豆包 AI 生成 或 Pexels 下载          │
│     ├─ 视频片段：Pika/Luma AI 生成 或 Pexels 下载           │
│     └─ 产品抠图：CapCut 智能抠图（产品图叠加到场景背景）      │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 配音（ElevenLabs）                                        │
│     └─ 脚本分段生成英文配音，下载 MP3                         │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 剪辑（CapCut）                                            │
│     ├─ 导入素材，按脚本顺序排列                                │
│     ├─ 图片加关键帧动画（缩放/平移）                           │
│     ├─ 导入配音，自动生成字幕                                  │
│     ├─ 加背景音乐（CapCut 库 / Suno）                         │
│     ├─ 加转场、贴纸、文字特效                                  │
│     └─ 调色，导出 1080p MP4                                   │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  5. 发布                                                      │
│     ├─ 各平台单独写标题/描述/标签（AI 生成）                  │
│     ├─ TikTok 优先发布（24小时后再发 Reels，避免判定搬运）    │
│     └─ 定时发布（TikTok/Instagram 都支持定时）                │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 批量生产流程（每周5-7条）

```
周一：选题会（AI 生成10个选题，人工选5-7个）
  │
周二：脚本批量生成（AI 一次生成5-7条脚本，人工微调）
  │
周三：素材准备（产品图+场景图+视频片段，集中处理）
  │
周四：配音批量生成（ElevenLabs 一次生成5-7条配音）
  │
周五：剪辑（CapCut 模板化，2-3小时完成5-7条）
  │
下周：排期发布（每天1条，定时发布）
```

## 6. 常见问题

### Q1：免费额度够每天1条吗？
**A**：够。ElevenLabs 10分钟/月 ≈ 20条30秒视频，Pika 4次/天 ≈ 120次/月，其他工具额度充足。如果需要每天2条，升级 ElevenLabs ($5/月) 即可。

### Q2：AI 生成的视频质量够吗？
**A**：Phase 1 冷启动够用。关键技巧：不要让 AI 直接生成产品，用真实产品图 + AI 场景背景 + CapCut 合成，这样既有真实产品又有精美场景。

### Q3：需要学剪辑吗？
**A**：CapCut 非常简单，1-2小时就能上手。核心功能：导入素材、自动字幕、关键帧动画、加音乐。模板库可直接套用，不需要专业剪辑技能。

### Q4：AI 配音听起来自然吗？
**A**：ElevenLabs 的配音质量很高，接近真人。选对音色（推荐 Adam/Rachel），调好参数（Stability 0.5-0.7），效果很好。户外类建议用稍带活力的音色。

### Q5：会有版权问题吗？
**A**：
- AI 生成的图片/视频：目前版权模糊，但商用基本没问题
- AI 配音：ElevenLabs 免费版可商用
- AI 音乐：Suno 免费版可商用（需确认最新条款），CapCut 音乐库可商用
- 素材库：Pexels/Pixabay/Unsplash 免费商用
- **建议**：重要内容保留生成记录，避免争议

### Q6：什么时候需要升级付费？
**A**：
- 每天产量超过1条 → 升级 ElevenLabs ($5/月)
- Pika 免费额度不够用 → 升级 Pika Pro ($10/月)
- 需要更快的 AI 响应和更好的脚本质量 → 升级 ChatGPT Plus ($20/月)
- Phase 2 规模化生产时 → 全面升级
