## ⚠️ API使用门槛要求（必读）

根据1688官方规定，使用跨境综合解决方案需满足以下门槛：

| 考核项 | 要求 | 说明 |
|--------|------|------|
| **月度GMV** | ≥ 160,000 元 | 通过1688站内及寻源通API成交的月销售额 |
| **单次调用GMV** | ≥ 0.5 元 | 月度销售额 / 月度API调用次数 |

**达标计算公式：**
```
单次调用GMV = 月度GMV ÷ 月度API调用次数
例如：
- 月度GMV = 160,000 元
- 月度调用 = 320,000 次
- 单次GMV = 0.5 元 ✅ 达标
```
