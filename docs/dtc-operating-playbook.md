## 4. DTC 单位经济模型 (UE) 重算

### 4.1 UE 公式（V2.0 全成本利润率公式的完整化）

**单件订单 UE 公式**：

```
单件净利润 = 售价 - 采购成本 - 头程物流 - 尾程物流 - 平台费 - 营销费 - 支付手续费 - 退货损耗 - 税费
单件净利润率 = 单件净利润 / 售价 × 100%
```

### 4.2 参数假设表（阶段 1 中国直发）

| 参数 | 假设值 | 依据/来源 | 需校准 |
|---|---|---|---|
| **售价** | $14.99 - $49.99 | `first_batch_20_products_plan.md` | ✅ 有实测值 |
| **采购成本** | ¥10-60（约 $1.4-8.4） | `first_batch_20_products_plan.md` | ✅ 有实测值 |
| **头程物流**（海运到美） | $1.5-3.0 / kg | 行业经验区间 | ⚠️ 需实查报价 |
| **尾程物流**（美国小包） | $3.5-8.0 / 单 | 中国直发专线 | ⚠️ 需实查报价 |
| **平台费** | 0（独立站，无平台佣金） | 战略选择 | — |
| **支付手续费** | 2.9% + $0.30（Stripe） | Stripe 公开费率 | ✅ 确定值 |
| **营销费（CAC）** | $10-25 / 单 | 阶段 1b 广告实测 | ⚠️ 阶段 1b 校准 |
| **退货率** | 8-15% | 户外品类行业经验 | ⚠️ 需实测 |
| **销售税** | 平均 7%（各州不同） | Stripe Tax 自动计算 | ✅ 系统计算 |
| **汇率** | 1 USD = 7.2 CNY | 项目基线假设 | ⚠️ 需实时校准 |

### 4.3 UE 场景测算（以露营氛围灯 $24.99 为例）

**假设**（数值为经验区间中值，需实测校准）：

| 项目 | 金额 (USD) | 说明 |
|---|---|---|
| 售价 | $24.99 | 定价 |
| - 采购成本 | -$3.00 | ¥22 @ 7.2 |
| - 头程海运 | -$0.30 | 0.15 kg |
| - 尾程小包 | -$5.50 | 中国直发 |
| - 支付手续费 | -$0.70 | 2.9% + $0.30 |
| - 营销费（CAC） | -$15.00 | 假设 CAC $15 |
| - 退货损耗 | -$1.00 | 4% 退货率 |
| - 销售税（假设） | -$1.75 | 7% |
| **= 单件净利润** | **-$2.26** | ⚠️ **负利润** |

**关键洞察**：
- **CAC 是最敏感变量**——CAC $15 时亏 $2.26，CAC $10 时盈利 $2.74，CAC $5 时盈利 $7.74
- **首月广告投放预算不能超 $500**——否则 CAC 失控
- **爆品效应**：一旦某款 SKU 日均订单 ≥ 3 单，可自然降低 CAC（有机流量占比上升）

|---|---|---|---|---|
| **引流款（< $15）** | $9.99-14.99 | ¥5-15 | 40-55% | ≤ $8 |
| **主力款（$15-30）** | $19.99-29.99 | ¥15-40 | 45-60% | ≤ $15 |
| **高客单（$30+）** | $34.99-59.99 | ¥40-100 | 50-65% | ≤ $25 |

### 4.5 盈亏平衡模型

**月盈亏平衡公式**：

```
盈亏平衡月订单 = 固定成本 / (单件售价 - 单件变动成本)
```

**假设参数**：
- 月固定成本：$3,000-5,000（服务器 + 插件 + 广告工具 + 人力）
- 单件售价：$24.99
- 单件变动成本：$22.99（不含 CAC）
- 单件毛利（不含 CAC）：$2.00

**盈亏平衡月订单**：$5,000 / $2.00 = **2,500 单**（极端悲观）

**修正后**（用实际毛利 45%）：
- 单件毛利：$11.25
- 盈亏平衡月订单：$5,000 / $11.25 = **445 单**

**关键判断**：
- 阶段 1b 目标 100 单/月 → **必然亏损**（属正常）
- 阶段 1c 目标 300 单/月 → **微亏或盈亏平衡**
- 阶段 2b 目标 500 单/月 → **盈利**

| 序列 | 触发条件 | 邮件数 | 目标 |
|---|---|---|---|
| **欢迎序列** | 首次订阅（含弃购客户） | 5 封（1/2/5/10/20 天） | 建立关系，首单转化 |
| **弃购序列** | 加购未结账 | 3 封（1h/24h/72h） | 挽回订单 |
| **复购序列** | 首单完成 30 天 | 4 封（30/60/90/120 天） | 二次购买 |
| **沉睡唤醒** | 90 天无购买 | 3 封（90/120/150 天） | 唤醒客户 |
| **季节性推送** | 特定日期 | 每月 2-4 封 | 品牌维护 |

**EDM 频率**：
- 每周 1-2 封（旺季增加至 3 封）
- 每月至少 1 封促销邮件
- Q4 旺季 3-4 封/月

**EDM 关键指标**：
- 打开率 ≥ 25%
- 点击率 ≥ 5%
- 转化率 ≥ 3%（相对订阅者）
- 退订率 ≤ 0.5%

**EDM 内容策略**：
- **主题行**：简洁、有钩子（"<50 words", "camping gear under $30", "new arrival"）
- **正文**：图文混排，主图 + 场景描述 + 明确 CTA
- **个性化**：使用姓、浏览历史、地区、季节定制
- **移动优化**：邮件模板移动优先

## 8. 决策树与路径分叉

### 8.1 阶段 1b 决策树（M6 决策点）

```
阶段 1b（M3-M6）结束
├─ 月订单 ≥ 100 + 毛利率 ≥ 25% + 至少 1 款爆品？
│  ├─ YES → 进入阶段 1c（品牌沉淀）
│  └─ NO
│     ├─ 月订单 < 50 → 复盘选品 + 广告
│     ├─ 毛利率 < 15% → 停止广告，重算 UE
│     └─ CAC > $30 → 停止广告，重估流量策略
│
└─ 若 3 个月内无进展 → 战略熔断，暂停扩张
```

### 8.2 阶段 1c 决策树（M9 决策点）

```
阶段 1c（M6-M9）结束
├─ 月订单 ≥ 300 + 复购率 ≥ 8% + 至少 2 款爆品？
│  ├─ YES → 进入阶段 2a（海外仓筹备）
│  └─ NO
│     ├─ 复购率 < 5% → 复盘产品与客户体验
│     ├─ CAC 持续 > $40 → 重估增长模型
│     └─ 爆品 < 1 款 → 复盘品类聚焦
│
└─ 若 3 个月内无进展 → 战略熔断，暂停扩张
```

### 8.3 阶段 2 决策树（M15 决策点）

```
阶段 2b（M12-M15）结束
├─ 海外仓启用 + 履约时效 < 7 天 + 月订单 ≥ 500？
│  ├─ YES → 进入阶段 2c（多市场扩展 + B2B 准备）
│  └─ NO
│     ├─ 库存周转 > 60 天 → 清仓 + 缩小备货
│     ├─ 退货率 > 15% → 停止上新，复盘产品
│     └─ 海外仓成本 > $12/单 → 重新谈判 3PL 合同
│
└─ 若海外仓运行 3 月仍无改善 → 退回中国直发，暂缓海外仓
```

### 8.4 阶段 2c 决策树（M18 决策点）

```
阶段 2c（M15-M18）结束
├─ 德国市场月订单 ≥ 100 + B2B 准备 100% + 月订单 ≥ 1000？
│  ├─ YES → 阶段 3 B2B 启动（详见 B2B 规划）
│  └─ NO
│     ├─ 德国市场未达标 → 暂缓德国，专注美国
│     ├─ B2B 准备未达 80% → 延后 B2B
│     └─ 全球订单 < 500 → 战略熔断
│
└─ 若 M18 全部未达标 → 战略复盘，考虑重新定位
```

### 8.5 战略熔断机制

**触发条件**（全部达标才熔断，避免误熔断）：
- 阶段 1b 3 月无进展（月订单 < 30 且 CAC > $40）
- 阶段 1c 3 月无进展（月订单不增长且复购率 < 5%）
- 阶段 2b 3 月无进展（海外仓成本 > $15/单且退货率 > 15%）
- 现金流断裂（< $5,000 运营金）

**熔断动作**：
- 停止所有广告投放
- 停止新 SKU 上架
- 库存清仓（清仓 50-70% off）
- 复盘根因（选品/供应链/流量/客户体验）
- 战略重定或暂停

## 结语

**M0-M18 阶段的核心任务**：

1. **跑通产品闭环**（阶段 1）：选品 → 上架 → 成交 → 履约 → 复购

3. **沉淀品牌资产**（阶段 1c）：爆品 + 复购 + KOL 关系
4. **升级履约能力**（阶段 2）：海外仓 + 本地化售后
5. **准备 B2B 入场**（阶段 2c）：能力准备，M18+ 启动

**关键红线**：
- 每个阶段结束必须复盘，未达熔断信号才能推进
- 数据是资产，所有决策必须基于实测数据
- 数据不足时诚实标注，不虚构数字
- 阶段 1-2 不做 B2B 客户开发
