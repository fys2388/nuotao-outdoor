## 🥇 方案一：Oracle Cloud（永久免费）

### 优势
- **真正永久免费**，不是试用
- 配置强大：ARM 4核24G 内存
- 全球多个数据中心可选

### 免费资源
| 资源 | 规格 | 数量 |
|---|---|---|
| ARM 计算实例 | Ampere A1，4核24G | 1台（可拆分为多台） |
| x86 计算实例 | AMD VM.Standard.E2.1.Micro，1核1G | 2台 |
| 块存储 | 200GB | - |
| 对象存储 | 10GB | - |
| 出站流量 | 10TB/月 | - |

### 注册步骤
1. 访问 https://www.oracle.com/cloud/free/
2. 点击 "Start for free"
3. 填写邮箱（建议使用 Gmail/Outlook）
4. 填写个人信息和信用卡（仅验证，不扣费）
5. 验证手机号
6. 等待审核（通常几分钟到几小时）

### 创建实例
1. 登录 Oracle Cloud Console
2. 导航到 Compute → Instances
3. 点击 "Create instance"
4. 选择 "Always Free-eligible" 形状
   - **推荐**: VM.Standard.A1.Flex（ARM，4核24G）
   - 或: VM.Standard.E2.1.Micro（x86，1核1G）
5. 选择操作系统：Ubuntu 22.04
6. 添加 SSH 公钥
7. 点击 "Create"

### 注意事项
- ⚠️ 注册需要信用卡验证（不会扣费）
- ⚠️ 部分地区可能无法注册（建议使用美国/香港地址）
- ⚠️ 长时间不使用可能被回收资源
- ⚠️ ARM 架构需要使用 ARM 兼容的 Docker 镜像

## 🥈 方案二：本地部署（零成本）

### 优势
- **完全免费**，不需要云服务器
- 数据完全在本地，隐私安全
- 开发调试方便

### 适用场景
- 开发测试阶段
- 个人学习使用
- 不需要公网访问

### 硬件要求
| 最低配置 | 推荐配置 |
|---|---|
| CPU: 2核 | CPU: 4核+ |
| 内存: 4GB | 内存: 8GB+ |
| 硬盘: 40GB | 硬盘: 80GB+ |
| 系统: Windows 10/11 或 Ubuntu 20.04+ | 系统: Ubuntu 22.04 LTS |

### 部署步骤
1. 安装 Docker Desktop（Windows/Mac）或 Docker Engine（Linux）
2. 克隆项目代码
3. 配置 `.env` 文件
4. 运行 `docker compose up -d`
5. 访问 http://localhost

### 公网访问方案（可选）
如果需要从外网访问本地服务，可以使用：
- **ngrok**: https://ngrok.com（免费版有流量限制）
- **frp**: 自建内网穿透（需要一台有公网 IP 的服务器）
- **Cloudflare Tunnel**: https://www.cloudflare.com/products/tunnel/（免费）

## 🥉 方案三：AWS Free Tier（12个月免费）

### 免费资源
| 资源 | 规格 | 免费额度 |
|---|---|---|
| EC2 实例 | t2.micro / t3.micro（1核1G） | 750小时/月（1台持续运行） |
| RDS 数据库 | db.t2.micro / db.t3.micro | 750小时/月 |
| S3 存储 | 标准存储 | 5GB |
| 出站流量 | - | 100GB/月 |
| CloudFront | CDN | 50GB/月 |

### 注册步骤
1. 访问 https://aws.amazon.com/free/
2. 点击 "Create a Free Account"
3. 填写邮箱、信用卡、手机号
4. 验证身份
5. 选择支持计划（Basic 免费）

### 创建 EC2 实例
1. 登录 AWS Console
2. 导航到 EC2 → Instances
3. 点击 "Launch instances"
4. 选择 Ubuntu Server 22.04 LTS
5. 选择 t2.micro（Free tier eligible）
6. 配置安全组（开放 22, 80, 443）
7. 创建/选择密钥对
8. 点击 "Launch"

### 注意事项
- ⚠️ 免费期 12 个月，之后按使用量计费
- ⚠️ 超出免费额度会自动扣费
- ⚠️ 建议设置 Billing 告警，避免意外扣费
- ⚠️ 12个月后 t2.micro 约 ¥10/月

## 🚀 部署后检查清单

无论选择哪种方案，部署完成后请检查：

- [ ] SSH 可以正常登录
- [ ] 80/443 端口已开放
- [ ] Docker 已安装并运行
- [ ] 域名已解析到服务器 IP
- [ ] SSL 证书已配置（HTTPS）
- [ ] 防火墙已配置（仅开放必要端口）
- [ ] 数据库已备份
- [ ] 监控告警已配置
- [ ] 默认密码已修改

## 💡 省钱技巧

1. **使用 ARM 架构**: Oracle Cloud ARM 实例性能更强且免费
2. **合理配置资源**: 不需要的服务不要启动，节省内存
3. **使用轻量数据库**: SQLite 适合小流量场景，不需要单独的数据库服务器
4. **定期清理**: 删除不需要的镜像、容器、卷
5. **设置预算告警**: 避免意外扣费
6. **多年付更优惠**: 阿里云/腾讯云多年付通常有折扣
7. **关注促销活动**: 双11、618、黑五等节日有大幅优惠

## ⚠️ 风险提示

1. **免费服务可能变更**: 云服务商可能随时调整免费政策
2. **资源可能被回收**: 长时间不使用的免费资源可能被回收
3. **技术支持有限**: 免费用户通常没有技术支持
4. **SLA 无保障**: 免费服务通常没有服务等级协议
5. **数据安全**: 重要数据请定期备份到本地或其他存储

---

**总结**: 对于 Nuotao AI OS 项目，建议开发阶段使用本地部署，正式上线后根据业务需求选择 Oracle Cloud（免费）或阿里云/腾讯云（国内业务）。
