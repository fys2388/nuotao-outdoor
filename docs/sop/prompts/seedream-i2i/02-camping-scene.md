# 主图 02 · 真实露营场景

> **对应 SOP**：`wc-ai-content-sop-v1.0.md` Phase ④
> **工具**：Seedream 5.0 Pro (I2I 图生图)
> **规格**：1:1 正方形，2048×2048

---

## 用途

展示产品使用场景，增强代入感。这是独立站产品页的核心"生活方式"图，直接影响买家对产品的场景联想。

## 构图规范

- **构图**：产品位于画面视觉中心，背景为真实户外场景
- **背景**：草地/森林/湖边/营地，自然虚化
- **光影**：自然光，上午或傍晚的柔和阳光
- **文字**：无文字、无水印

---

## Prompt 模板（Seedream I2I）

```
参考[img0]作为产品外观参考，保持产品的形状、颜色、材质、结构100%不变。
将产品放置在真实的户外露营场景中，背景是绿色草地和远处的森林，
阳光从侧面照射，形成自然的光影效果。
产品位于画面视觉中心，占画面约50%，背景适度虚化突出产品。
整体采用户外生活方式摄影风格，自然真实的光线，温暖的色调，
画面中可以有露营帐篷、野餐垫等环境元素作为点缀，但不抢夺产品焦点。
无任何文字或水印。关键主体完整置于安全边界内，四周边距均衡。
```
