# 主图 04 · 产品结构细节

> **对应 SOP**：`wc-ai-content-sop-v1.0.md` Phase ④
> **工具**：Seedream 5.0 Pro (I2I 图生图)
> **规格**：1:1 正方形，2048×2048

---

## 用途

展示产品的结构设计和工艺细节。让客户对产品的做工有信任感。

## 构图规范

- **构图**：产品侧面/俯视/局部特写，展示关键结构
- **背景**：浅灰色或浅色渐变背景
- **光影**：侧光突出材质纹理和结构层次
- **文字**：无文字、无水印

---

## Prompt 模板（Seedream I2I）

```
参考[img0]作为产品外观参考，保持产品的形状、颜色、材质、结构100%不变。
采用侧面视角展示产品的结构设计，产品位于画面中央，占画面约60%。
背景采用浅灰色渐变背景，干净简洁。
光线从左侧照射，形成自然的明暗对比，突出产品的材质纹理和结构层次。
可以看到产品的[关键结构1]、[关键结构2]、[关键结构3]等细节部位。
整体采用专业产品细节摄影风格，清晰锐利，质感强烈。
无任何文字或水印。关键主体完整置于安全边界内。
```

---

## 品类差异化调整

| 品类 | 关键结构展示 |
|---|---|
| 折叠家具 | 折叠铰链、支架结构、面料缝线 |
| 照明产品 | LED 灯珠、开关按钮、充电接口、散热结构 |
| 水具产品 | 瓶盖密封结构、提手、材质纹理 |
| 炊具产品 | 炉头结构、挡风板、点火装置 |
| 收纳产品 | 拉链、提手、分隔层、面料纹理 |
| 帐篷/庇护所 | 面料涂层、帐杆结构、地钉配件 |
| 户外配件 | 材质工艺、接口细节、表面处理 |

no text, no chinese characters, no other brand logo,
