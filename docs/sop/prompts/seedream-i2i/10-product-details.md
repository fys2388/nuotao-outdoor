# 详情 10 · 产品细节

> **对应 SOP**：`wc-ai-content-sop-v1.0.md` Phase ④
> **工具**：Seedream 5.0 Pro (I2I 图生图)
> **规格**：3:4 竖版，1536×2048

---

## 用途

特写展示产品的材质、工艺、配件等细节。建立产品品质感。

## 构图规范

- **构图**：3:4 竖版，上方标题，中间 3 格特写拼图，下方说明
- **背景**：每格独立的特写背景
- **文字**：标题 + 每格细节名称

---

## Prompt 模板（Seedream I2I）

```
参考[img0]作为产品外观参考，保持产品的形状、颜色、材质、结构100%不变。
竖版3:4构图，画面上方是标题"PRODUCT DETAILS"（大号粗体字体，深灰色），
中间是3格横向排列的特写拼图，每格展示一个产品细节：
- 左格：[细节1]特写，如面料纹理，展示材质质感
- 中格：[细节2]特写，如缝线工艺，展示做工精细
- 右格：[细节3]特写，如金属配件，展示坚固耐用
每格下方有小号英文细节名称标签。
画面下方有一段简短的产品工艺说明文字（小号字体，中灰色）。
背景采用浅灰色到白色的渐变背景，干净现代。
整体采用专业产品细节摄影风格，特写清晰锐利，质感强烈。
关键主体与文字完整置于安全边界内。
```
