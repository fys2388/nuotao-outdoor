# 主图 05 · 多色/多规格展示

> **对应 SOP**：`wc-ai-content-sop-v1.0.md` Phase ④
> **工具**：Seedream 5.0 Pro (I2I 图生图)
> **规格**：1:1 正方形，2048×2048

---

## 用途

展示产品的多种颜色或规格选项。提升客户选择感和购买意愿。

## 构图规范

- **构图**：2-3 个不同颜色的产品并排或错落排列
- **背景**：纯白或浅色背景
- **光影**：均匀柔和的光线
- **文字**：无文字、无水印

---

## Prompt 模板（Seedream I2I）

```
参考[img0]作为产品外观参考，保持产品的形状、结构100%不变。
展示[数量]个不同颜色的同款产品，并排排列在画面中，
颜色分别为：[颜色1]、[颜色2]、[颜色3]。
产品位于画面中央，整体占画面约70%，排列整齐有层次。
背景采用纯白色背景，干净清爽。
光线均匀柔和，每个产品都有清晰的展示，下方有轻微接触阴影。
整体采用专业电商产品摄影风格，色彩准确还原。
无任何文字或水印。关键主体完整置于安全边界内。
```

---

## 常见颜色组合

| 风格 | 颜色组合 |
|---|---|
| 户外经典 | 卡其色 + 军绿色 + 黑色 |
| 活力配色 | 橙色 + 蓝色 + 灰色 |
| 简约配色 | 黑色 + 白色 + 灰色 |
| 自然配色 | 棕色 + 绿色 + 米色 |
| 大地色系 | 深棕 + 浅棕 + 沙色 |
| 现代科技 | 黑色 + 深蓝 + 银灰 |

---

## I2I 参考图选择

**首选**：1688 多色图（不同颜色）
**次选**：1688 白底图（Prompt 要求生成多个颜色变体）

**⚠️ 关键**：颜色必须与 1688 实际售卖颜色一致，不能凭空生成。
如果 1688 只有 1 个颜色，则跳过此图或改为"同色不同规格"展示。

---

## 负面提示词

```
no text, no chinese characters, no other brand logo,
no color distortion, no fake colors,
keep product shape identical for all variants,
no blur, no cartoon style,
keep product structure 100% identical across colors
```

---

## 验收 Checklist

- [ ] 产品外观与 1688 原图 100% 一致（形状、结构）
- [ ] 所有变体颜色与 1688 实际售卖颜色一致
- [ ] 2-3 个变体并排排列
- [ ] 整体占画面约 70%
- [ ] 纯白背景
- [ ] 光线均匀柔和
- [ ] 每个产品下方有接触阴影
- [ ] 分辨率 2048×2048
- [ ] 色彩准确还原
