# 生图验收 Checklist

> **对应 SOP**：`wc-ai-content-sop-v1.0.md` Phase ④
> **对应闸口**：C4 图片审批（`POST /image-gen/tasks/{id}/approve`）
> **使用场景**：每张图生成后必须过一遍

---

## 通用验收（每张图必过）

### 1. 产品外观一致性（100% 还原）

- [ ] 形状与原图 100% 一致
- [ ] 颜色与原图 100% 一致
- [ ] 材质纹理与原图 100% 一致
- [ ] 结构细节与原图 100% 一致
- [ ] Logo 位置与原图 100% 一致

### 2. 文字正确性

- [ ] 所有可见文字为英文
- [ ] 无中文残留
- [ ] 无拼写错误
- [ ] 无乱码
- [ ] 文字清晰可读

### 3. 背景干净度

- [ ] 无水印
- [ ] 无其他品牌 Logo
- [ ] 无多余元素
- [ ] 背景符合 Prompt 描述

### 4. 构图合理性

- [ ] 产品完整在画面内，无裁切
- [ ] 比例协调（按 Prompt 要求）
- [ ] 关键主体在安全边界内
- [ ] 四周边距均衡

### 5. 光影自然度

- [ ] 光影方向一致
- [ ] 无违和感
- [ ] 质感真实
- [ ] 产品下方有自然阴影

---

## 11 张图整体验收

### 6. 视觉多样化

- [ ] 11 张图背景有明显差异
- [ ] 11 张图角度有明显差异
- [ ] 11 张图光影有明显差异
- [ ] 11 张图构图有明显差异

### 7. 信息完整性

- [ ] 产品外观展示（主图 01/04/05）
- [ ] 使用场景展示（主图 02/详情 09）
- [ ] 核心卖点展示（主图 03/详情 07）
- [ ] 结构细节展示（主图 04/详情 08/10）
- [ ] 品牌背书展示（详情 06/11）

### 8. 品牌一致性

- [ ] 品牌名拼写一致
- [ ] 色调一致
- [ ] 风格一致
- [ ] Logo 位置一致

### 9. 转化率优化

- [ ] 首图有吸引力
- [ ] 促销图有卖点
- [ ] 详情页有信任背书
- [ ] 品质保障图有承诺

---

## 11 张图规格验收

| 图编号 | 类型 | 尺寸 | 分辨率 |
|---|---|---|---|
| 01 白底 | 主图 | 1:1 | 2048×2048 |
| 02 场景 | 主图 | 1:1 | 2048×2048 |
| 03 促销 | 主图 | 1:1 | 2048×2048 |
| 04 结构 | 主图 | 1:1 | 2048×2048 |
| 05 多色 | 主图 | 1:1 | 2048×2048 |
| 06 品牌 | 详情 | 3:4 | 1536×2048 |
| 07 卖点 | 详情 | 3:4 | 1536×2048 |
| 08 结构 | 详情 | 3:4 | 1536×2048 |
| 09 场景 | 详情 | 3:4 | 1536×2048 |
| 10 细节 | 详情 | 3:4 | 1536×2048 |
| 11 保障 | 详情 | 3:4 | 1536×2048 |

- [ ] 所有主图 1:1 比例，2048×2048
- [ ] 所有详情图 3:4 比例，1536×2048
- [ ] 文件 ≤ 500KB / 张
- [ ] 格式为 JPG 或 WebP

---

## AI 崩坏检查

- [ ] 无手指错误（6 指等）
- [ ] 无文字乱码
- [ ] 无 logo 变形
- [ ] 无比例扭曲
- [ ] 无光影矛盾
- [ ] 无颜色偏差
- [ ] 无材质失真

---

## 合规检查

- [ ] 无侵权元素（其他品牌 Logo、名人肖像）
- [ ] 无虚假宣传元素（医疗宣称等）
- [ ] 无敏感内容（暴力、色情等）
- [ ] 文化敏感性检查（针对目标市场）

---

## 通过后动作

1. 标记为 `pending_review`
2. 上传到 `/image-gen/tasks/{id}/approve`
3. 等待人工审批（闸口④）
4. 审批通过 → 进入 Phase ⑤ 文案生成
