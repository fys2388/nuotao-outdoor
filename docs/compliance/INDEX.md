## 关键洞察

1. **1688 一件代发能力普遍薄弱**：5 条里只有 SKU #1 的代发能力强（900+ 单），其余 4 条都是 <10 单。这可能是因为这些供应商主要走批发，未主动接分销商。但供应商资质都过硬（多为四星/五星），协商后大概率可开代发通道。

2. **跨境合规字段填写质量参差**：SKU #1/#3 填得最完整（下游平台+地区+授权+专利），SKU #2/#5 只填"其他"或未填。这不是供应商能力问题，是 1688 商家运营意识问题，不影响实际合规。

3. **质检/检测报告普遍缺失**：5 条里只有 SKU #1 有官方验货徽章（3 项）。其他 4 条都需要向供应商索取。这是**亚马逊上架的硬阻塞项**（美国站户外品类需报告），必须下单前拿齐。

4. **件重尺表数据质量差**：SKU #4 直接填 1×1×1 占位，SKU #2 尺寸合理，SKU #3 疑似填外箱尺寸。这说明 1688 商家对件重尺的填写普遍不严谨，成本模型需要用毛重 ×1.15 保守估算而不是依赖 1688 表格。
