# M4.2 Supply Chain Agent — API 规格设计（API Spec）

> 版本：v1.0
> 日期：2026-11-21
> 阶段：M4.2 第一阶段（现状审计 + 架构设计，不含代码实施）
> 决策身份：ChatGPT Owner
> 执行身份：DSH（执行 Agent）
> 上游依据：`M4.2_AGENT_DESIGN.md`、`M4.2_ARCHITECTURE.md`、`docs/AGENTS.md` §2.4
> 规范基座：`backend/app/api/v1/endpoints/supply_chain.py` + `supply_chain_learning.py`

---

## 1. API 设计原则

| # | 原则 | 落地 |
|---|---|---|
| API-1 | **对齐规范基座** | 新增 endpoint 一律遵循 `supply_chain.py` 范式：Pydantic schema + `response_model` + 服务层 + `event_service` + `trace_id` + workspace 隔离 |
| API-2 | **规避技术债** | **不依赖** GAP D 标记的 6 个裸 dict router（purchase_automation/procurement_workbench/fulfillment/inventory/logistics/overseas_warehouse）；Agent 数据源只用 M4.1 规范表 |
| API-3 | **统一错误结构** | 所有响应 `{ "code", "message", "data", "trace_id" }`（AGENTS.md §2.4） |
| API-4 | **权限校验** | 写操作强制 `get_current_user` + `get_workspace_id`；审批操作叠加 `approval_rbac` |
| API-5 | **审计** | 所有写操作经服务层写 `event_log`；Agent 运行写 `ai_agent_runs` / `AgentExecution` |
| API-6 | **幂等** | 触发类 endpoint 支持 `idempotency_key` |
| API-7 | **本轮只设计** | endpoint 实现属代码实施，Owner 审批后才编写 |

## 3. 新增 Endpoint 规格

### 3.1 Agent 运行入口

#### `POST /supply-chain-agent/tasks`
触发一次 Supply Chain Agent 分析/建议生成任务。

| 项 | 值 |
|---|---|
| 权限 | `get_current_user` + `get_workspace_id` |
| 请求 schema | `SupplyChainTaskCreateRequest`：`{ capability: enum(supplier_analysis\|cost_analysis\|procurement_decision\|inventory_forecast\|learning_calibration), product_id?: Uuid, supplier_id?: Uuid, location?: enum(cn\|us\|eu), params?: dict, idempotency_key?: str }` |
| 响应 schema | `SupplyChainTaskOut`：`{ task_id, agent_run_id, status, trace_id }` |
| 行为 | 校验实体存在 → `agent_runtime.create_task`（幂等）→ `task_queue.enqueue_task` → 事件 `agent.supply_chain.task_created` |
| 审计 | `AgentExecution` + `event_log` + `trace_id` |
| 错误 | 未知实体 404；重复幂等键复用任务（返回同 task_id） |

#### `GET /supply-chain-agent/tasks/{task_id}`
查询任务状态与结果。

| 项 | 值 |
|---|---|
| 响应 schema | `SupplyChainTaskDetailOut`：`{ task_id, status, capability, input, output, suggestion_ids, execution: { status, cost, tokens, latency_ms, tool_calls }, trace_id }` |
| 错误 | 未知/跨工作区 404 |

#### `GET /supply-chain-agent/tasks`
列出任务（`status`/`capability`/`product_id` 过滤，分页）。

### 3.2 建议产出与审批闭环

#### `GET /supply-chain-agent/suggestions`
列出 Supply Chain Agent 产出的建议（对接 `agent_suggestions`，`suggestion_type IN (supply_chain, inventory_restock)`）。

| 项 | 值 |
|---|---|
| 过滤 | `status`(pending_approval/approved/rejected/...)、`risk_level`、`product_id` |
| 响应 schema | `list[SupplyChainSuggestionOut]`（含结构化 `execution_params`） |

#### `GET /supply-chain-agent/procurement-decisions`
列出结构化采购决策（`procurement_decisions` 表）。

| 项 | 值 |
|---|---|
| 过滤 | `approval_status`、`product_id`、`supplier_id` |
| 响应 schema | `list[ProcurementDecisionOut]`（含推荐供应商/采购量/目标价/MOQ匹配/预期到货/决策理由/规则评估快照） |

#### `GET /supply-chain-agent/procurement-decisions/{decision_id}`
采购决策详情。

#### `POST /supply-chain-agent/procurement-decisions/{decision_id}/approve`
**人工审批**采购决策（`pending_approval` → `approved`）。

| 项 | 值 |
|---|---|
| 权限 | `get_current_user` + `approval_rbac.check_approval_permission`（供应链审批权限） |
| 请求 schema | `DecisionApproveRequest`：`{ actor: str, note?: str }` |
| 行为 | 条件 UPDATE 抢占（防双审）→ 经统一审批中心 `_dispatch` → 联动 `agent_suggestions.approve` → 事件 `supply_chain.decision_approved` |
| 审计 | `approved_by/at` + `event_log` + `trace_id` |
| 错误 | 非 pending 400；越权 403；二次审批 400 |

#### `POST /supply-chain-agent/procurement-decisions/{decision_id}/reject`
**人工拒绝**（同上，→ `rejected`）。

> **审批闭环说明**：审批通过**不等于自动下单**。生成内部采购单须经 `fulfillment_service`（`draft`/`pending_approval`），永不直接 `approved`。执行侧是否生成采购单、生成数量，由独立的执行编排（受控）决定，仍留审计。

### 3.3 供应商智能（复用 + 增强）

#### `GET /supply-chain-agent/suppliers/{supplier_id}/risk-scorecard`
供应商风险评分卡（聚合画像 + 评估历史 + 模式挖掘 + 报价历史）。

| 项 | 值 |
|---|---|
| 响应 schema | `SupplierRiskScorecardOut`：`{ supplier_id, risk_score, risk_level, confidence, model_version, calibrated_at, components: {quality, on_time, defect, capacity, price_stability}, evidence: [...], source_trace_id }` |
| 数据源 | `supplier_profiles`（新增 risk_score 字段）+ `supplier_ai_evaluations` + `supplier_pattern_runs` + `supplier_quote_history` |
| 只读 | 无副作用 |

#### `GET /supply-chain-agent/products/{product_id}/supplier-comparison`
多供应商比价（基于 `product_sourcing_candidates` + `supplier_quote_history`）。

| 项 | 值 |
|---|---|
| 响应 schema | `SupplierComparisonOut`：`{ product_id, candidates: [{supplier_id, quote_price, moq, lead_time_days, valid_until, risk_score, landed_cost_estimate, confidence}], recommendation }` |

---

### 3.4 成本智能核算

#### `GET /supply-chain-agent/products/{product_id}/landed-cost`
落地成本 + 置信度（复用 `cost_model_service`/`profit_engine`，补 source/confidence）。

| 项 | 值 |
|---|---|
| 响应 schema | `LandedCostOut`：`{ product_id, breakdown: {...}, total_landed_cost, source, confidence, cost_status(KNOWN/ESTIMATED/UNKNOWN), warnings }` |
| 约束 | UNKNOWN 成本返回降级警告，**不得给出高置信盈利结论**（对齐 profit_engine） |

#### `GET /supply-chain-agent/products/{product_id}/cost-variance`
成本预测 vs 实际偏差（`cost_prediction_vs_actual`）。

| 项 | 值 |
|---|---|
| 响应 schema | `list[CostVarianceOut]`：`{ predicted, actual, variance, variance_pct, accuracy, confidence_bucket, model_version }` |

---

### 3.5 库存与履约预测

#### `GET /supply-chain-agent/products/{product_id}/demand-forecast`
需求预测（`demand_forecasts` 最新 active）。

| 项 | 值 |
|---|---|
| 响应 schema | `DemandForecastOut`：`{ product_id, location, horizon_days, daily_demand, total_demand, confidence, confidence_bucket, model_version, method }` |
| 约束 | 数据不足返回低置信度，**禁止伪造预测** |

#### `GET /supply-chain-agent/products/{product_id}/reorder-recommendation`
再订货建议（基于库存 + 需求预测 + 安全库存）。

| 项 | 值 |
|---|---|
| 响应 schema | `ReorderRecommendationOut`：`{ product_id, current_stock, reorder_point, safety_stock, days_of_supply, stockout_risk, recommended_quantity, reasoning }` |
| 说明 | 这是**读类计算**（L1，产出信息）；若要转为行动建议须经 L3 工具写 `procurement_decisions`/`agent_suggestions` |

#### `GET /supply-chain-agent/products/{product_id}/inventory-movements`
库存变动历史（`inventory_movements` append-only）。

#### `GET /supply-chain-agent/stockout-events`
缺货/履约风险事件列表（过滤 severity/product/location）。

### 3.6 学习闭环（复用 + 扩展 `supply_chain_learning`）

复用现有 `supply_chain_learning.py` 的 12 个 endpoint（评估/模式/校准），新增：

#### `GET /supply-chain-agent/calibration/runs/{run_id}/writeback-plan`
查看校准提案的**回写计划**（人审后如何回写业务参数，GAP 方向 E 缺口）。

| 项 | 值 |
|---|---|
| 响应 schema | `CalibrationWritebackPlanOut`：`{ run_id, status, suggested_params, target_entities: [{type: supplier_profile\|rule, id, field, current, proposed}], requires_human_approval: true }` |
| 约束 | **只读计划**；实际回写须经人工审批，走 StrategyVersion/规则版本，留审计 |

#### `POST /supply-chain-agent/sampling-reviews`
线上建议抽样人工复核（回流评测集）。

| 项 | 值 |
|---|---|
| 请求 schema | `SamplingReviewCreateRequest`：`{ suggestion_id, human_rating: int(1-5), comment?: str }` |
| 行为 | 写复核记录 → 更新建议 `feedback_*` → 回流评测集候选 |
| 审计 | `event_log` + `trace_id` |

## 4. 复用的现有 Endpoint（不新增）

Supply Chain Agent 的**工具层**经服务层取数，但对外暴露的管理/查询能力**复用**现有规范 endpoint：

| 能力 | 复用 endpoint |
|---|---|
| 供应商 CRUD | `supply_chain.py` `/suppliers`、`/supplier-profiles` |
| 采购单管理 | `supply_chain.py` `/purchase-orders`（**唯一规范状态机**） |
| 库存快照 | `supply_chain.py` `/inventory-snapshots` |
| 运单/物流 | `supply_chain.py` `/shipments`、`/shipments/{id}/events` |
| 知识记忆 | `supply_chain.py` `/supply-chain-knowledge-entries` |
| 供应商评估/模式/校准 | `supply_chain_learning.py` 12 个 endpoint |
| 通用审批中心 | `/approvals`（RBAC + SLA） |
| 通用建议队列 | `agent_suggestions` 相关 endpoint |

> **明确不暴露/不依赖**：GAP D 的 6 个技术债 router、`supply_chain.py` 末尾原生 SQL 旁路端点（`/purchase-orders/stats`、`PATCH /status`）。

## 5. 统一错误码（AGENTS.md §2.4）

| 错误码 | HTTP | 场景 |
|---|---|---|
| `SUPPLY_AGENT_TASK_NOT_FOUND` | 404 | 任务/决策/实体不存在或跨工作区 |
| `SUPPLY_AGENT_INVALID_CAPABILITY` | 422 | capability 枚举非法 |
| `SUPPLY_AGENT_DECISION_NOT_PENDING` | 400 | 采购决策非 pending 状态，不可审批 |
| `SUPPLY_AGENT_ALREADY_DECIDED` | 400 | 二次审批（防重） |
| `SUPPLY_AGENT_FORBIDDEN` | 403 | 审批 RBAC 越权 |
| `SUPPLY_AGENT_IDEMPOTENCY_REUSED` | 200 | 幂等键复用（返回原任务，非错误） |
| `SUPPLY_AGENT_COST_UNKNOWN` | 200(降级) | 成本 UNKNOWN，返回降级警告 |
| `SUPPLY_AGENT_FORECAST_INSUFFICIENT_DATA` | 200(降级) | 需求预测数据不足，低置信度 |

## 6. 权限矩阵

| Endpoint 类别 | 权限 |
|---|---|
| 读类（scorecard/comparison/cost/forecast/reorder/movements） | `get_current_user` + workspace |
| 任务触发（POST tasks） | `get_current_user` + workspace |
| 审批（approve/reject decision） | `get_current_user` + `approval_rbac`（供应链审批权限） |
| 抽样复核（sampling-reviews） | `get_current_user`（运营角色） |
| Agent 内部 L3 工具 | 运行时 `permission_engine`（L3 → waiting_approval → 审批中心） |
