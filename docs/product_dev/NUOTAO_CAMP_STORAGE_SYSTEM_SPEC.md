## 1. 产品概述

### 1.1 产品名称
**Nuotao CampKit 5-Box Categorical Storage System**（5箱分类露营收纳系统）

### 1.2 产品定位
针对车营(Car Camping)和房车(RV)家庭用户的**系统化露营收纳解决方案**。解决"Storage Bin Jenga"痛点——传统收纳箱48小时内崩溃、找物品需翻8件物品、缺乏场景化分类。

### 1.3 核心卖点
1. **场景化分类**: 5个箱子对应5个使用场景（睡眠/厨房/工具/照明/杂物）
2. **防水标签**: 每个箱子配防水标签贴纸，告别"忘记颜色编码"
3. **模块化堆叠**: 箱子可堆叠、可组合、可独立使用
4. **尺寸系列**: 大/中/小三种尺寸，适配不同空间

### 1.4 目标用户
| 属性 | 描述 |
|------|------|
| 核心用户 | 25-55岁车营/房车家庭 |
| 活动类型 | 周末露营、多日露营、长期露营 |
| 购买动机 | 减少"pre-trip friction"，降低打包时间 |
| 价格接受度 | $80-150（套装） |
| 证据来源 | ClutterScience + CampgroundViews + Sprinter-Source |

## 2. 产品规格

### 2.1 尺寸规格

| 箱子 | 用途 | 内部尺寸 (LxWxH) | 外部尺寸 (LxWxH) | 容量 | 重量 |
|------|------|-------------------|-------------------|------|------|
| BOX-1 (L) | 睡眠区 | 28"x16"x12" | 30"x18"x13" | ~36L | 1.8kg |
| BOX-2 (M) | 厨房区 | 24"x14"x10" | 26"x16"x11" | ~28L | 1.5kg |
| BOX-3 (M) | 工具区 | 24"x14"x10" | 26"x16"x11" | ~28L | 1.5kg |
| BOX-4 (S) | 照明区 | 18"x10"x8" | 20"x12"x9" | ~18L | 1.1kg |
| BOX-5 (S) | 杂物区 | 18"x10"x8" | 20"x12"x9" | ~18L | 1.1kg |

**设计原则**:
- 箱体比例适配美国车厢/房车内部空间
- 箱子之间可完美堆叠（高度递增，稳定）
- 底部平坦，无倾斜面（解决"sloped sides"痛点）

### 2.2 材质规格

| 部件 | 材质 | 规格 | 说明 |
|------|------|------|------|
| 箱体 | PP（聚丙烯） | 食品级 | 耐低温-20°C，耐冲击 |
| 密封圈 | TPE（热塑性弹性体） | 食品级 | 防水防虫 |
| 卡扣 | PP+ABS | 加厚设计 | 3处卡扣/箱，单手开合 |
| 提手 | PP | 加厚防滑纹 | 可承重10kg |
| 标签 | PVC防水贴纸 | 3M背胶 | 可反复书写擦拭 |
| 标签笔 | 可擦式油性笔 | 配1支/套 | 随套装赠送 |

**竞品对比**:
- IRIS USA: PP材质，橡胶密封圈，$25-40
- Rubbermaid: PP材质，$15-22
- Nuotao: PP+TPE双层密封，差异化在于系统化设计

| 箱子 | 颜色 | 标签颜色 | 用途标识 |

- 场景化颜色编码，直觉式记忆
- 标签可替换，用户可自定义
